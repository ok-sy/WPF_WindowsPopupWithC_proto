# 팝업 설정 사용자 가이드

## 1. 문서 목적

이 문서는 관리자 화면에서 팝업을 등록하거나 수정하는 사용자를 위한 설정 설명서다.

내부 클래스나 DB 컬럼보다는 실제 화면에서 어떤 값을 선택할 수 있고, 선택했을 때 사용자 PC의 WPF 팝업이 어떻게 동작하는지를 중심으로 설명한다.

현재 팝업 유형은 다음 다섯 가지다.

- TEXT: 일반 안내문
- IMAGE: 이미지 안내
- VIDEO: 영상 안내/교육
- SURVEY: 설문
- QUIZ: 퀴즈/평가 (`동영상 + 퀴즈` 선택 시 QUIZ + videoEnabled로 저장)

---

## 2. 공통 설정

### 2.1 기본 정보

| 화면 항목 | 실제 값 | 설명 |
|---|---|---|
| 팝업 ID | `popupId` | 팝업을 구분하는 고유값. 저장 후 변경하지 않는 것을 권장 |
| 팝업 제목 | `title` | 사용자 팝업 상단 Header에 표시되는 제목 |
| 팝업 유형 | `TEXT`/`IMAGE`/`VIDEO`/`SURVEY`/`QUIZ` | 팝업 콘텐츠 형태 |
| 노출 시작 | `displayStartAt` | 서버 시각 기준 이 시각부터 조회 대상 |
| 노출 종료 | `displayEndAt` | 서버 시각 기준 이 시각 이후에는 더 이상 조회되지 않음 |
| 노출 요일·시간대 지정 | `periodMode` (`FIXED`/`SCHEDULE`) | 끄면 노출 기간 내 상시(`FIXED`). 켜면 노출 기간 안에서 아래 요일·시간대에만 조회 대상(`SCHEDULE`, TODO52-1) |
| 노출 요일 | `repeatDayOfWeek` (`1,3,5`, 1=월) | 고르지 않으면 매일. 여러 개 선택 가능 |
| 노출 시간대 | `displayTimes[]` (`startTime`~`endTime`, HH:mm) | 개수 제한 없음. 없으면 하루 종일. 종료가 시작보다 이르면 다음 날까지(자정 초과, 요일은 시작 기준). 서버 한국 시간 기준 |
| 팝업 활성화 | active | 켜져 있어야 사용자 조회 대상이 됨 |

로그인/기동 직후 최초 조회한다. 서버가 지금 표시할 팝업을 표시 우선순위 순으로 **한 번에 1건**만 내려주므로 PC 시각을 바꿔도 노출 대상 판단은 바뀌지 않는다(설계 35). 사용자가 팝업을 닫거나 제출하면 결과를 저장한 뒤, 남은 팝업이 있으면 바로 다음 1건을 조회하고 없으면 30~60분 조회 간격만큼 기다린다. 팝업이 떠 있는 동안에는 다른 팝업을 조회하지 않는다. 표시할 팝업이 없던 동안 새로 노출 가능해진 팝업의 실제 표시는 다음 조회까지 최대 약 60분 지연될 수 있다.

닫은 팝업의 재표시 기준은 다음과 같다.

- 텍스트·이미지: 닫기(바로가기 포함)하면 완료로 처리되어 노출 기간 안에 다시 표시하지 않는다.
- 설문·퀴즈·영상: 제출·통과·시청 완료 전에 닫으면 조회 간격(30~60분) 동안 다시 표시하지 않고, 그 뒤에도 노출 조건을 만족하면 다시 표시한다.
- 다시 보지 않기: 숨김 일수 동안 표시하지 않는다.
- 요일·시간대 지정(TODO52-1): 반복은 미완료 팝업이 보일 수 있는 일정일 뿐이며 반복일마다 새로 응답받지 않는다. 완료한 팝업은 이후 요일·시간대에도 다시 표시하지 않고, 다시 보지 않기 기간에는 일정과 관계없이 표시하지 않는다. 나중에 보기는 다음 조회 주기에 다시 고르며 그때가 시간대 밖이면 다음 유효 시간대에 표시한다. 조회 간격(30~60분) 때문에 짧은 시간대나 다른 팝업을 보는 동안 지나간 시간대의 팝업은 표시되지 않을 수 있다(예: 9·10·11시 시간대 팝업 중 9시 팝업을 12시에 닫으면 10·11시 팝업은 놓친다).

### 2.2 표시 방식

| 화면 선택 | 실제 값 | 동작 |
|---|---|---|
| 순차 표시 | `SEQUENTIAL` | 같은 우선순위 팝업을 한 개씩 표시 |
| 동시 표시 | `SIMULTANEOUS` | 같은 우선순위의 팝업을 여러 창으로 동시에 표시하는 값. 현재 WPF는 서버에서 팝업을 1건씩 받아 표시하므로 실제로는 순차 표시와 같게 동작한다(설계 35) |

### 2.3 표시 우선순위

`displayOrder` 숫자가 작을수록 먼저 표시된다. 서버가 이 값으로 정렬해 첫 1건만 사용자 PC에 내려주며, 같은 번호이면 먼저 등록한 팝업(같으면 팝업 ID 순)이 먼저다.

예:

```text
팝업 A: displayOrder 10
팝업 B: displayOrder 10 (A보다 나중 등록)
팝업 C: displayOrder 20
→ A 표시 → 닫기·제출 → B 표시 → 닫기·제출 → C 표시
```

`displayOrder`는 서버 정렬에만 쓰며 WPF 조회 응답에는 포함하지 않는다.

## 3. 노출 대상 설정

관리자 화면에서는 대상 그룹과 조건을 만들 수 있다.

같은 그룹 안의 조건은 모두 만족해야 하고, 서로 다른 그룹끼리는 하나만 만족해도 된다.

```text
그룹 내부 = AND
그룹 사이 = OR
```

현재 선택 가능한 조건은 다음과 같다.

| 조건 | 설명 |
|---|---|
| 부서 | 특정 부서 대상. 하위 부서 포함 가능 |
| 직급 | 특정 직급 대상 |
| 사번 | 특정 사용자 대상 |
| 입사일 | 특정 날짜와 비교 |

입사일은 같음/같지 않음/이전/이전 또는 당일/이후/이후 또는 당일 비교를 사용할 수 있다.

## 4. 팝업 크기

### 4.1 고정 크기

화면 선택: `고정 크기`

팝업 너비와 높이를 픽셀로 직접 지정한다.
입력값은 설정된 최소/최대 범위 안으로 자동 보정된다. 최소·최대 너비/높이는 크기 설정에서 입력한다(기본 300×300 ~ 1200×900). 창 최소 크기는 가로·세로 각각 300px 이상이어야 저장된다(TODO68). 실제 팝업(WPF)은 같은 수치를 화면 배율 기준 논리 크기로 쓰므로 DPI 배율에 따라 물리 픽셀 수는 달라질 수 있다. 전체 화면에서는 사용하지 않고, 이미지 팝업은 최소 크기만 입력하며 최대는 작업 영역의 90%다. 이미지 우선(FIT_TO_IMAGE)의 너비·높이는 이미지 영역 크기이고 최소 300×300은 헤더·푸터를 더한 최종 창에 적용된다.

### 4.2 화면 비율

화면 선택: `화면 비율`

현재 모니터 크기에 비례해 팝업 크기를 계산한다.

예:

```text
너비 비율 0.7
높이 비율 0.75
```

이면 모니터 작업 영역의 약 70% × 75% 크기로 표시된다.

> 관리자 화면·서버·WPF API 문자열은 `RATIO`로 통일되어 있다.

### 4.3 전체 화면

화면 선택: `전체 화면`

주 모니터 전체를 사용한다.
일반 팝업의 고정 너비/높이 값은 사용하지 않는다.

### 4.4 자동 크기

WPF에는 콘텐츠 크기에 맞춰 창 크기를 정하는 `AUTO` 기능이 구현되어 있지만 현재 관리자 화면에서는 선택할 수 없다.

## 5. 공통 화면 표시 옵션

| 화면 옵션 | 설명 |
|---|---|
| 헤더 표시 | 상단 제목 영역 표시. 오른쪽에는 클릭되지 않는 고정 로고만 있고 닫기(X) 버튼은 없다 |
| 닫기 표시 | 하단 푸터 버튼 표시. 버튼 문구는 동작에 따라 `닫기` / `바로가기`, 설문·퀴즈는 `제출`. WPF 응답의 `showFooterButton`에 해당 |
| 푸터 표시 | 하단 영역 표시 |
| 다시 보지 않기 | 사용자가 일정 기간 팝업을 숨길 수 있는 체크박스 표시 |
| 푸터 버튼 동작 | `닫기`(기본) 또는 `바로가기 (링크 열고 닫기)`. 설문·퀴즈·동영상+퀴즈는 `제출` 고정(11.1 참고) |
| 다시 보지 않기 숨김 일수 | 다시 보지 않기 선택 시 숨길 일수(1~3650). 비우면 WPF 기본 30일. WPF 체크박스 문구도 `{N}일간 보지 않기`로 같은 일수를 표시 |
| 배경 클릭 차단 | 팝업이 열려 있는 동안 모든 모니터의 배경 클릭을 막고 배경을 어둡게 표시. 키보드 전환은 막지 않음. 기본 사용 |
| 배경 어둡기 (%) | 배경 클릭 차단 사용 시 배경 어둡기 0~100%. 기본 45% |
| 주 모니터 표시 위치 | 작업 표시줄을 제외한 주 모니터 영역 기준 9방향(중앙·왼쪽 위·위쪽 중앙 등). 기본 중앙. 전체 화면에서는 선택할 수 없음 |
| 폰트 크기 (헤더·본문·푸터 px) | 영역별 글자 크기. 비우면 기본 크기(헤더 17, 본문 유형별 12~15, 푸터 14). 입력값은 10~40으로 보정 |

주의사항:

- WPF 팝업의 닫기 버튼은 푸터 버튼 하나다. 헤더에는 X 버튼이 없으며 그 밖의 종료 경로는 Alt+F4다. 배경 Overlay를 켜면 화면에 닫기·제출 버튼이 있는 팝업은 Alt+F4로 닫히지 않는다(버튼이 하나도 없으면 Alt+F4 허용). Esc로는 닫히지 않는다. 관리자 미리보기도 헤더에 같은 고정 로고를 표시한다.
- 푸터 또는 닫기 표시를 끄면 일반 팝업의 푸터 버튼이 보이지 않는다. 설문·퀴즈의 제출 버튼은 닫기 표시와 관계없이 유지된다.
- 푸터를 끄면 다시 보지 않기 체크박스도 사용할 수 없다.
- 다시 보지 않기 숨김 일수는 관리자에서 지정할 수 있고, 비워 두면 WPF 기본 30일을 사용한다.

## 6. TEXT 팝업

TEXT는 일반 안내문을 서식 본문과 하단 설명으로 구성한다(강조 문구는 2026-10-29 삭제). 콘텐츠 제목·설명은 별도 입력란 없이 서식 본문 앞 문단으로 작성한다(설계 37).

### 6.1 선택 가능한 구성

| 화면 기능 | 설명 |
|---|---|
| 일반 텍스트 | 서식 편집기로 입력하는 본문 영역. 제목·설명도 앞 문단으로 입력하고 서식(굵게·크기 등)으로 구분 |
| 하단 설명 | 본문 아래 추가 문장. 하단 설명 연결 URL을 넣으면 클릭 시 브라우저로 이동 |

### 6.2 서식 편집

일반 텍스트는 서식 편집기로 입력한다. 글자를 선택한 뒤 우클릭하거나 `서식` 버튼을 누르면 서식 패널이 열린다. 패널에는 글자 색 격자(8계열 × 밝기 5단계)가 펼쳐져 있고 같은 패널에서 글꼴·크기·굵게·기울임·밑줄·취소선을 고른다. 일괄 서식 초기화·색 초기화 버튼은 없으며 각 서식 버튼을 다시 누르거나 글꼴·크기를 `기본`으로 골라 되돌린다(TODO66). 적용해도 패널은 열려 있어 연속으로 바꿀 수 있으며 Esc나 바깥 클릭으로 닫는다. 문단 정렬(왼쪽·가운데·오른쪽)과 들여쓰기는 툴바 및 우클릭 패널에서 설정한다(TODO62). 들여쓰기 늘리기·줄이기 버튼으로 한 단계(40px)씩 지정하며 단계 수 제한은 없다(TODO63). 내어쓰기는 0단계에서 멈춘다. 저장 시 서식 본문(`textBlocks`)과 서식을 뺀 일반 텍스트(`plainText`)를 함께 저장하며 WPF와 미리보기는 서식 본문을 기준으로 표시한다(설계 28).

> 왼쪽·오른쪽 카드 구성은 없다. Markdown 모드는 2026-09-21 제거했다.

## 7. IMAGE 팝업

### 7.1 기본 항목

| 화면 항목 | 설명 |
|---|---|
| 콘텐츠 제목 | 이미지 위/주변 제목 |
| 설명 | 이미지 설명 |
| 이미지 URL | 표시할 이미지 주소 |
| 이미지 설명 표시 | 설명 노출 여부 |

### 7.2 이미지 크기 모드

| 선택 | 설명 |
|---|---|
| 원본 그대로 (넘치는 부분 자르기) | `ORIGINAL`. 원본 픽셀 크기를 유지해 왼쪽 위에 표시하고, 팝업보다 큰 부분은 자름. 스크롤/확대·축소 없음. 제목·설명은 쓰지 않고 이미지만 표시(이미지 클릭 링크는 계약 3.7에서 삭제) |
| 이미지 우선 | `FIT_TO_IMAGE`. 입력한 콘텐츠 너비·높이(이미지 영역, 비우면 원본)에 헤더·푸터·설명 공간을 더해 팝업 창 크기를 계산. 실제 창은 입력값보다 커질 수 있고 최대 창 크기를 넘는 부분은 잘린다 |
| 창 우선 | `ADAPTIVE`. 입력한 팝업 창 크기 안에 이미지 비율을 유지해 맞춤. 원본보다 확대하지 않음 |

신규 등록 기본값은 **창 우선(ADAPTIVE)**이다. 관리자 화면은 저장된 값이 없거나 과거 값(`FIXED` 등)인 데이터를 ADAPTIVE로 불러온다(다시 저장하면 정리). 서버 조회는 FILL만 변환하고 WPF는 FIXED 등 과거 값을 받으면 표시하지 못하므로, DB의 과거 값은 `db/oracle/06_image_size_mode_adaptive_oracle.sql`로 정리한다. `꽉 채우기(FILL)` 모드는 설계 23에서 제거했다. 세부 동작은 아래 "IMAGE 크기 선택"을 참고한다.

## 8. VIDEO 팝업

### 8.1 기본 설정

| 화면 항목 | 설명 |
|---|---|
| 콘텐츠 제목 | 영상 내부 제목 |
| 설명 | 영상 설명 |
| 영상 URL | 재생할 영상 주소/경로 |
| 완료 비율 | 전체 영상 중 몇 %를 시청해야 완료로 인정할지 지정 |
| 기본 음량 | 0~1 사이 값. Windows 볼륨 연결 전/실패 시 초기값으로 사용 |

### 8.2 선택 기능

| 기능 | 설명 |
|---|---|
| 영상 설명 표시 | 영상 설명 영역 표시 |
| 컨트롤 표시 | 재생 컨트롤 표시 여부 |
| 전체화면 허용 | 영상 자체 전체화면 사용 허용 |
| 배속 변경 허용 | 사용자의 재생속도 변경 허용 |
| 재생 위치 변경 허용 | 진행바 클릭·드래그·키보드로 재생 위치를 바꾸는 것을 허용. 끄면 탐색을 막고 진행률·시간 표시는 유지 |
| 자동 재생 | 팝업이 열리면 자동 재생 |
| 반복 재생 | 종료 후 반복 |

완료 비율을 충족하기 전에는 닫기 버튼(동영상)·퀴즈 입력과 제출(동영상+퀴즈)이 항상 잠긴다. 예전 `완료 전 닫기 허용` 옵션은 폐기했다(TODO57). 완료 전에 화면 버튼으로 나가게 하려면 `나중에 보기`를 켠다. Alt+F4 등 키보드 닫기는 `배경 클릭 차단`이 켜져 있으면 막히고(완료 후에도 동일), 꺼져 있으면 완료 전이라도 닫히며 시청 기록은 그대로 저장된다. 강제 시청이 필요하면 배경 클릭 차단 켜짐 + 푸터 표시 + 나중에 보기 끔으로 설정한다(영상 재생 실패·프로그램 종료는 예외).

로컬 파일과 직접 재생 가능한 HTTP/HTTPS 영상은 영상 하단에 겹치는 같은 컨트롤바를 사용한다. 재생 중 마우스를 영상 밖으로 옮기거나 일반 화면 3초·영상 전체화면 2초 동안 조작하지 않으면 숨겨지고 마우스를 영상에 넣거나 움직이면 나타난다. 일시정지·조작 중에는 표시를 유지한다. 재생·일시정지·탐색·배속·전체화면을 같은 옵션으로 조작하고 URL 영상의 브라우저 기본 컨트롤은 표시하지 않는다. 음량·음소거는 현재 Windows 시스템 값과 동기화한다. 음량을 올리면 시스템 음소거도 해제하며 음소거 버튼은 음량을 유지한 채 음소거만 전환한다. 다른 프로그램의 소리에도 영향을 주며 팝업을 닫아도 마지막 설정이 유지된다. 시스템 볼륨에 연결할 수 없을 때는 영상 자체 음량을 조절한다. 컨트롤 표시를 끄면 영상 클릭으로 재생/일시정지를 전환할 수 있다. 배속 변경을 금지하면 URL 영상도 1.0배를 유지하며, 전체화면 금지는 영상 플레이어에 적용된다(팝업 창 자체 전체화면과 별개). 버퍼링 중에는 중앙 로딩 표시가 나타난다.

WPF는 실제 재생한 구간의 누적 시청시간과 최대 도달 위치를 모아 종료/제출 시 서버로 전송하고 서버가 최종 완료를 판정한다. 탐색으로 건너뛴 구간은 시청시간에 넣지 않는다.

## 9. SURVEY 팝업

SURVEY는 질문을 추가하고 사용자의 응답을 서버에 저장하는 팝업이다.

현재 관리자 화면에서 선택 가능한 문항 유형은 다음과 같다.

| 문항 유형 | 설명 |
|---|---|
| 객관식 · 단일 선택 | 하나만 선택 |
| 객관식 · 복수 선택 | 여러 개 선택. 퀴즈는 정답으로 체크한 개수만큼만 응답자가 선택할 수 있다(TODO52-5) |
| 주관식 | 직접 텍스트 입력 |

각 문항은 다음 값을 설정할 수 있다.

- 문항 제목
- 문항 설명
- 필수 문항 여부
- 선택지

### 9.1 선택지 배치

등록 화면의 각 선택형 문항에서 세로형(기본) 또는 가로형을 선택한다. 한 설문·퀴즈 안에서 문항마다 다른 배치를 사용할 수 있다. 가로형은 공간이 부족하면 다음 줄로 이어지고 긴 선택지 문구도 줄바꿈한다.

선택지는 직접 입력한다. RATING5 유형은 삭제했고 기존 문항은 단일 선택 + 가로 배치로 이관했다(2026-09-28).

WPF 데모(`popupSample.exe --demo`)에서 **옵션 설정** 창의 문항별 배치 선택으로 서버 없이 확인할 수 있다.

## 10. QUIZ 팝업

QUIZ는 SURVEY와 같은 질문 화면을 사용하지만 채점 기능이 추가된다.

설정 가능한 항목은 다음과 같다.

- 문항 제목/설명
- 필수 문항
- 문항별 배점
- 객관식 정답 선택
- 주관식 정답
- 주관식 정답 비교 방식
- 통과 점수

주관식 정답 비교 방식:

| 선택 | 설명 |
|---|---|
| 정확히 일치 | 입력값이 정답과 같아야 함 |
| 포함 | 입력값에 정답 문자열이 포함되는지 확인 |

최종 점수와 통과 여부는 WPF에서 로컬 채점한다. 통과한 경우에만 `SUBMITTED` 결과를 만들고 `score`와 `passed`를 서버에 전송한다.

설문·퀴즈·동영상+퀴즈는 모두 `제출` 버튼을 사용한다. 공통 푸터가 있으면 내부 버튼을 숨겨 제출 버튼 하나만 제공한다. 동영상+퀴즈는 시청 기준 충족 후 제출할 수 있다. 미응답·불합격은 공통 안내창(불합격은 점수와 틀린 문항 번호 포함)을 표시하고 답안을 수정할 수 있도록 창을 유지한다. 설문·퀴즈의 푸터 동작은 제출로 고정되어 바로가기 링크를 열지 않는다. Alt+F4는 제출 없이 종료하는 별도 경로이며 배경 Overlay가 켜져 있으면 막힌다(헤더에는 X 버튼이 없다). 퀴즈는 배경 Overlay를 끈 경우 한 번 불합격한 뒤 푸터에 보조 `닫기`가 나타나고, 동영상+퀴즈는 영상 재생 실패 시에만 보조 `닫기`를 표시한다. 시청 기준 전 동영상+퀴즈의 제출과 동영상의 닫기 버튼은 비활성이며 현재 시청 %와 기준을 함께 표시한다. 시청 기준 전 이탈은 `나중에 보기`로 한다(TODO57).

단일 선택은 원형 Radio 표시 없이 선택지 전체를 클릭하는 카드로 표시한다. 짧은 가로형 선택지는 Chip으로 표시하고 긴 문장은 자동 줄바꿈한다. 선택·포커스는 회색 명암과 테두리로 표현하고 활성 제출 버튼은 #4A4A4F 진회색을 사용하고 Hover #3D3D42·Pressed #303035로 표현한다. 주관식 입력창의 안내 문구는 실제 답안으로 저장되지 않는다. 필수 문항 미응답 시 제출 버튼은 비활성화되고 하단에 응답 현황·남은 문항 수를 표시한다. 필수 응답 완료 후 버튼이 활성화되며 입력을 지우면 다시 비활성화된다. 키보드 Tab·Space 및 선택지에서 Enter를 사용할 수 있다.

문항은 그림자 없이 매우 연한 배경의 그룹으로 구분한다. 세로 단일·복수 선택지는 흰 배경과 약한 테두리, 항상 보이는 우측 체크 Path로 구분한다. 선택 시 연회색 배경과 진한 체크로 강조하고 가로형 단일·복수 선택은 동일한 Chip 구조로 표시하며 기본 원형·사각 체크 UI를 숨긴다. 복수선택은 여러 Chip을 동시에 선택할 수 있다. 긴 문장에서도 체크는 우측 중앙에 고정되며 선택 전후 높이를 유지한다. 주관식은 긴 입력에서 내부 스크롤을 사용한다. 본문을 스크롤해도 제출 영역은 하단에 고정되며 VIDEO+QUIZ에서 공통 푸터를 끈 경우에도 내부 제출 버튼은 고정된다.

## 11. 동영상 + 퀴즈

등록 화면에서 **동영상 + 퀴즈**를 선택하면 API에는 별도 popupType을 만들지 않고 `popupType=QUIZ`, `content.videoEnabled=true`로 저장한다.

- 영상 누적 시청 비율이 완료 기준에 도달하기 전에는 퀴즈와 푸터가 비활성화된다.
- 완료 기준에 도달하면 퀴즈 입력과 푸터가 활성화된다.
- 영상 끝으로 건너뛴 것만으로는 누적 시청 기준을 충족하지 않는다.
- 통과 제출 시 답안·점수·영상 시청 정보를 하나의 결과로 보낸다.
- 영상·전체 문항은 세로 스크롤 하나로 이동하고 제출 영역은 공통 푸터 사용 여부와 관계없이 창 하단에 고정한다. 단독 설문/퀴즈의 스크롤은 기존과 같다. 영상 결합은 QUIZ에만 지원하며 VIDEO+SURVEY 모드는 없다.
- 완료 비율 0.8은 누적 80% 시청을 뜻하고, 비우면 100%다. 영상은 로컬 파일 경로 또는 직접 재생 가능한 HTTP(S) 영상 URL을 사용한다.
- 영상 컨트롤바는 영상 위에 겹쳐 표시되므로 표시·숨김 중에도 영상 높이가 바뀌지 않는다. 재생 옵션은 VIDEO 팝업(8.2)과 같다.
- 시청 기준과 퀴즈 통과를 모두 충족해야 완료된다. 영상만 시청하고 닫은 경우 퀴즈 완료로 처리하지 않는다.
- 필수 문항이 없으면 선택 문항 안내를 표시하며 바로 제출할 수 있다.
- 관리자 미리보기의 **시청 비율** 슬라이더로 퀴즈·푸터의 비활성/활성 상태를 확인할 수 있다. 실제 영상 플레이어가 아니라 미리보기 도구다.
- 영상 URL은 `POPUP_CONTENT.MEDIA_URL`, 모드·푸터 옵션은 `CONTENT_OPTIONS`에 저장한다. 통과 제출 결과의 점수·통과 여부는 결과 요청의 `score`·`passed`로 전송한다(일반 퀴즈와 동일, 재전송 큐에도 보존).

### 11.1 푸터 바로가기

텍스트·이미지·동영상 팝업에서 **푸터 표시**·**닫기 표시**를 켠 뒤 푸터 버튼 동작을 **바로가기 (링크 열고 닫기)**로 선택하고 바로가기 URL(http/https)을 입력한다. 하단 버튼은 `바로가기`로 표시되며 누르면 `footerLinkUrl`을 기본 브라우저로 연 뒤 팝업을 닫는다. 링크는 푸터 버튼을 누른 경우에만 연다. URL이 잘못되었거나 브라우저 실행에 실패하면 팝업을 유지한다. 설문·퀴즈·동영상+퀴즈는 **제출**로 고정되어 바로가기를 선택할 수 없다.

## 12. 사용자가 팝업에서 수행하는 동작과 서버 처리

### 팝업 열기

```text
사용자 팝업 조회 (서버가 1건 선택)
→ 표시 대상/기간/숨김·완료·재노출 유예 상태 확인
→ WPF 표시
→ WPF 내부 표시 시각 기록
```

### 팝업 닫기

```text
닫기
→ CLOSED 결과를 로컬 큐에 저장
→ 결과 API로 1건 전송
→ 다음 팝업이 있으면 바로 조회
```

### 다시 보지 않기

```text
다시 보지 않기 체크
→ 닫기
→ 서버에 사용자 + 팝업 ID + 숨김 기간 저장
```

숨김 일수를 비워 두면 WPF 기본 30일을 사용한다.

### 설문/퀴즈 제출

```text
답안 입력
→ 제출
→ WPF 로컬 검증/채점
→ SUBMITTED 결과를 로컬 큐에 저장
→ 결과 API로 1건 전송
→ 다음 팝업이 있으면 바로 조회
```

### 영상 재생

```text
재생
→ 위치/누적 시청시간 측정
→ 누적 시청시간/위치 기록
→ 종료 시 VIDEO_WATCHED 또는 제출 결과의 video 블록 전송
```

`**` IMAGE의 화면 비율은 이미지 크기 모드가 `원본 그대로`일 때만 선택할 수 있다. 다른 모드는 이미지 크기 모드 쪽 너비·높이를 사용한다.

`***` 동시 표시는 설정 값으로 남아 있으나 WPF가 서버에서 팝업을 1건씩 받아 표시하므로 실제로는 순차 표시와 같다(설계 35).

표의 `O`는 해당 팝업 유형에서 지원되는 기능을 의미하며, `-`는 해당 유형에 적용되지 않는 기능을 의미한다.

## 14. 현재 관리자 화면에서 바로 설정할 수 없는 항목

다음은 기능 또는 필드는 존재하지만 현재 관리자 화면에서 완전하게 설정할 수 없는 항목이다.

- WPF `AUTO` 창 크기
- 서버 내부 반복 노출 정책의 세부 설정

IMAGE ORIGINAL, `hideDays`, 푸터 바로가기, 동영상+퀴즈 및 VIDEO 재생 옵션은 최신 main 기준 관리자 화면과 WPF에 연결되어 있다.

RATING5 문항 유형은 삭제했다(직접 입력한 단일 선택 보기 사용). 남은 미결 항목은 [`design/09_전환계획_및_미결사항.md`](design/09_전환계획_및_미결사항.md)에서 관리한다.

## IMAGE 크기 선택 (설계 23)

창 우선은 입력한 창에 전체 이미지를 원본 비율로 맞춘다. 이미지 우선은 입력한 이미지 크기에 창을 맞추며, 원본 비율 고정을 끄면 너비·높이를 독립 입력해 왜곡할 수 있다. 이미지가 창 최대보다 크면 자동 축소하지 않고 중앙에서 자른다. 잘림을 피하려면 입력 크기를 줄이거나 창 우선을 선택한다. 설명은 선택적으로 하단에 표시하고 긴 설명은 그 영역에서 스크롤한다. 원본 그대로는 기존 왼쪽 위 배치·잘림을 유지한다.
