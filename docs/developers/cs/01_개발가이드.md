# CS(WPF) 개발 가이드

> 담당: `popup-frameWork` .NET WPF 클라이언트, 창/콘텐츠 렌더링, 결과 큐, 로그인·폴링·배포. [API v3.7](../../interfaces/POPUP_INTERFACE_SPEC.md)과 [POLICY](../../policies/POLICY.md)를 계약 기준으로 사용한다.

## 실행 모델
- 보안 프로그램과 유사한 **상시 백그라운드 실행**. 트레이 기본 미표시.
- **최초 사용자 세션 실행 시 HKCU 자동 시작 1회 등록**, 이후 사용자가 시작프로그램을 해제하면 강제 재등록하지 않는다. SYSTEM 설치 실행과 사용자 실행을 구분한다.
- 선택적 `--tray`는 상태·진단 용도. 일반 사용자용 `--exit`와 트레이 종료 메뉴는 신규 개발 **제외(C)**. 기존 OS 종료·로그오프·운영 도구 종료 대응은 유지.
- 보안팀 소프트웨어 매니저를 통한 배포는 **미확정**이며 자동 시작 중복 관리 여부는 후속 확인.

## 화면 유형
- TEXT: RichText·스크롤·서식.
- IMAGE: FIT_TO_IMAGE/ADAPTIVE/ORIGINAL/FULLSCREEN과 공통 창 크기·Header/Footer.
- VIDEO: WebView2, 재생바·시청 완료율·완료 전 확인 비활성 조건.
- SURVEY: 단일/복수 선택·주관식·필수/최소/최대.
- QUIZ: O/X·객관식·정답 ID 기반 채점·커트라인형/만점형/참여형. VIDEO+QUIZ는 QUIZ + `content.videoEnabled=true`.
- 수신 화면설계서 V0.5는 [recieve_plan0.5](../../design/recieve_plan0.5.md), 현행 동작은 계약/정책을 우선. 화면 사진만으로 정책을 바꾸지 않는다.

## 결과·조회
- 로그인→서버 단건 조회→팝업 표시→CLOSED/HIDDEN/SUBMITTED/VIDEO_WATCHED 등 결과 1건 전송→`nextStatus`.
- **결과 큐는 메모리 전용 전환 결정**, 파일 기반 큐 읽기/쓰기·복원은 제거 대상. **현재 구현 완료로 간주하지 않는다.**
- 종료 시 미전송 결과 유실 허용. 네트워크 오류·400 격리·INTERNAL_ERROR 재시도 한도는 확정 계약과 B 미결을 구별한다.
- VIDEO/QUIZ 완료 전 닫기, Overlay, Later, 키보드·강제 종료는 유형별 정책과 검증 기록 대조.

## 성능·배포
- `AllowsTransparency`·WebView2·DPI·Horizon·저사양 PC 성능을 실제 장비로 확인.
- MSI offline-export 신규 개발은 폐기. 폐쇄망 반입은 현재 승인된 소스/산출 방식과 실제 보안팀 운영 확정 여부를 구분한다.
