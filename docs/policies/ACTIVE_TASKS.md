# 활성 작업 분류 — 진행 판단 / 정책 정의 / 폐기·대체 / 상태 정리

- 재분류일: 2026-11-03 (KST). 같은 날 C 보완: 2026-10-27~29 날짜형 TODO의 후속 결정(결과 큐 메모리 전용, 3117 사번 조회·등록 시 기본값)으로 덮인 항목을 원본 미체크와 대조해 C로 이동.
- 기준: 기존 TODO71 원본 전수조사([INVENTORY](../reviews/TODO71/INVENTORY.md)), [충돌·보류 검토](../reviews/TODO71/CONFLICTS.md), TODO53 및 개별 TODO의 구현·검증 기록.
- **주의:** 이 표는 문서·이력 기준의 **업무 성격 분류**다. 최신 배포 상태·실기기 검증을 새로 수행한 완료 판정이 아니다. 원본 체크 수와 활성 작업 수는 다르다.
- 이번 결정 반영은 활성 색인·검토 문서·변경 이력에 한정한다. 원본 TODO·정책 파일·코드·계약은 변경하지 않는다. 기존 TODO의 미체크를 자동으로 완료/폐기하지 않는다.

## 분류 기준

| 분류 | 판단 기준 | 다음 행동 |
|---|---|---|
| **A. 진행·검증 판단** | 기능·계약의 방향은 정해졌고 구현/인계/실환경 확인이 남았거나 최신 구현 상태 확인이 필요 | 코드·테스트·실환경 증거를 확인해 진행/완료/미실행 판정 |
| **B. 정책 정의 필요** | 값·범위·충돌 처리·책임 경계가 미확정이거나 명시적으로 보류됨 | 선택지·현행 임시 동작·영향을 제시하고 결정 후 계약/구현 반영 |
| **C. 폐기·후속 대체** | 폐기 결정이 있거나 후속 TODO가 구 계약을 대체함 | 실행 대상에서 제외, 원본은 이력으로 보존. 관련 기능 전체 폐기와 구별 |
| **D. 원문 상태 정리** | 본문 구현 기록과 체크박스·머리말이 모순되거나 오래된 체크가 남음 | 근거 확인 후 체크/상태 문구만 별도 정정; 동작 변경 금지 |

한 TODO가 A+B 또는 A+D에 걸칠 수 있다. **문서 단위로 일괄 완료/폐기하지 말고 세부 항목 단위로 처리한다.**
