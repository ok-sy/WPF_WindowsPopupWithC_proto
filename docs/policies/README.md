## 사용·보존 규칙

- 새로운 확정 변경은 해당 정책·계약·근거 TODO를 함께 갱신한다. 코드와 문서가 다르면 충돌로 기록하고 코드만 보고 확정하지 않는다.
- 완료·대체·폐기된 원본도 docs/design의 현재 경로에 보존한다. 원본 이동 이점보다 기존 링크/외부 인계 영향이 커 이번에는 이동하지 않는다.
- [활성 작업](ACTIVE_TASKS.md)은 원본 미완료·실환경 검증·보류를 연결한다. 새 TODO를 복제하거나 과거 미완료를 자동 부활시키지 않는다.
- [주석 분류](../reviews/TODO71/comments.csv)는 유지 이유와 정책 연결 대상을 기록한다. 역사 표식을 일괄 삭제하지 않는다.
- 샘플·테스트·배포 절차는 장기 계약으로 승격하지 않고 해당 정책의 연결 근거로 둔다. POL-13(저장), POL-14(샘플), POL-16(검증)은 서로의 책임을 대체하지 않는다.

## 검증 수준

이번 수행은 정적 문서/코드 경계 대조와 링크·역추적·주석 외 토큰 불변 검사다. 원격 DB·Windows·실제 관리자 UI·폐쇄망·타 팀 인계는 재검증하지 않았다. 과거 테스트 건수는 원본의 당시 증거이며 이번 실행 건수가 아니다.

검증 명령: `python3 scripts/audit-policy-docs-71.py` (저장소 루트). 상세 한계와 잔여 작업은 [검토 보고서](../reviews/TODO71/CONFLICTS.md)를 따른다.
