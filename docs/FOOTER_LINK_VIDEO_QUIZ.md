# 바로가기 푸터와 동영상 + 퀴즈

## 관리자 설정

1. 표시 옵션에서 **푸터 표시**·**닫기 표시**를 켜고, **푸터 버튼 동작 → 바로가기 (링크 열고 닫기)**를 선택한다.
2. 바로가기 URL을 입력한다. 일반 콘텐츠의 하단 버튼은 `바로가기`로 표시되며 브라우저 실행 성공 후 팝업을 닫는다. 기본 `닫기` 모드도 선택할 수 있다. 설문·퀴즈·동영상+퀴즈는 `제출` 버튼으로 응답 검증·채점 후 링크를 연다.

설문·퀴즈·동영상+퀴즈의 실행 버튼은 `제출`로 통일한다. 푸터가 있으면 내부 제출 버튼은 숨겨 동영상+퀴즈에도 제출 버튼 하나만 표시한다. 푸터가 없으면 내부 버튼을 사용한다. 필수 응답 누락·불합격은 안내 후 답안을 수정할 수 있도록 창을 유지한다. 통과하면 답안·점수·통과 여부·시청 정보를 함께 저장하고 창을 닫는다. 헤더 X/Alt+F4는 제출 없이 종료하는 별도 경로다.

필수 문항 미응답 상태에서는 제출 버튼이 비활성화되고 왼쪽에 응답 현황·남은 문항 수를 표시한다. 필수 문항이 모두 응답되면 버튼이 활성화된다. 필수 문항이 없으면 선택 문항 안내를 표시하며 제출할 수 있다. VIDEO+QUIZ는 영상 시청 잠금도 해제되어야 제출할 수 있다. 공통 푸터를 쓰면 내부 안내·버튼 영역을 숨겨 중복을 방지한다.

본문 스크롤과 제출 영역은 분리한다. VIDEO+QUIZ에서 공통 푸터를 끈 경우에도 내부 제출 영역을 스크롤 밖의 하단에 고정한다. 공통 푸터를 켜면 내부 영역을 숨기고 공통 푸터만 표시한다.
3. 팝업 유형에서 **동영상 + 퀴즈**를 선택하고 영상 URL·완료 비율·퀴즈 문항·배점·통과 점수를 설정한다. 완료 비율 0.8은 누적 80% 시청을 뜻하고, 비우면 100%다.
4. 영상 아래에 퀴즈가 표시된다. 시청 기준 전에는 퀴즈와 푸터 전체가 비활성화되고, 기준에 도달하면 활성화된다. 영상을 끝으로 건너뛰어도 누적 시청이 부족하면 활성화되지 않는다.
5. 미리보기의 **시청 비율** 슬라이더로 비활성/활성 상태를 확인할 수 있다. 이 슬라이더는 실제 영상 플레이어가 아닌 관리자 미리보기 도구다.

영상 재생 실패 시 퀴즈를 열어 주지 않는다. 헤더 닫기 또는 Alt+F4로 종료할 수 있다. 동영상+퀴즈 영상은 로컬 파일 경로 또는 직접 재생 가능한 HTTP(S) 영상 URL을 사용한다.

WPF의 로컬 파일·HTTP/HTTPS 직접 영상은 영상 하단에 겹치는 같은 WPF Overlay 컨트롤바를 사용한다. 재생·일시정지·탐색·배속·전체화면 옵션을 공통으로 적용하고 URL 영상의 브라우저 기본 controls는 표시하지 않는다. 음량·음소거는 Windows 시스템 값과 동기화하고 다른 프로그램에도 영향을 주며 종료 시 마지막 값을 유지한다. 장치 연결 실패 시 내부 플레이어 음량을 사용한다. 컨트롤은 별도 높이를 차지하지 않아 표시·숨김 중 영상 높이가 바뀌지 않는다. 영상·전체 문항은 단일 스크롤로 이동하며 제출 영역은 공통 푸터 사용 여부와 관계없이 창 하단에 고정한다. 단독 설문/퀴즈는 기존 자체 스크롤을 유지한다.

## WPF 데모

`Popup.exe --demo`의 왼쪽 상단 **새 기능 확인**에서 서버 없이 실행한다. 바로가기 URL(기본 `https://example.com/`)과 영상 완료 비율(0·25·50·80·100%, 기본 80%)을 바꿀 수 있다. **동영상+퀴즈 푸터에도 바로가기 사용**을 체크하면 두 기능을 함께 확인한다. **ORIGINAL 이미지** 버튼은 원본 자르기 모드로 바로 실행한다. 퀴즈 완료 점수·통과 여부는 오른쪽 상단 요약과 요청 JSON에 표시한다. 완료된 팝업을 다시 보려면 **서버 상태 초기화**를 누른다. 왼쪽 목록은 스크롤할 수 있다.

## 저장 및 결과

- API 유형은 기존 `QUIZ`, 추가 옵션은 `content.videoEnabled: true`다. 관리자 UI의 `VIDEO_QUIZ` 선택값은 저장 전에 QUIZ로 변환된다.
- 영상 URL은 기존 `POPUP_CONTENT.MEDIA_URL`, 모드·푸터 옵션은 `CONTENT_OPTIONS`에 저장한다. 새 테이블·컬럼·DDL 적용은 필요 없다.
- 제출 결과에는 퀴즈 답안·점수·통과 여부와 영상 시청 정보를 함께 보낸다. 영상만 시청하고 닫은 경우 퀴즈 완료로 처리하지 않는다.
- 완료 점수는 요청 JSON의 `results[].score`, 통과 여부는 `results[].passed`다. 예: `{"resultType":"SUBMITTED","score":87.5,"passed":true}`(관련 필드 발췌). 일반 퀴즈와 동영상+퀴즈 모두 동일하며 재전송 큐에도 점수를 보존한다.
- 시청 기준과 퀴즈 통과를 모두 충족해야 완료된다. 기존 일반 퀴즈의 통과 시 자동 종료 동작은 유지한다. 푸터 바로가기는 푸터 버튼을 클릭한 경우에만 실행한다.
- WPF와 서버를 함께 갱신해야 새 모드가 동작한다. 상세 계약은 `docs/interfaces/POPUP_INTERFACE_SPEC.md` v3.5를 참고한다.
