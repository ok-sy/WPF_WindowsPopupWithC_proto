# 선택지 배치 및 줄바꿈 확인

## 설정 계약

- 등록 화면 각 문항의 선택지 배치: 세로형 / 가로형. 선택지는 직접 입력한다.
- API: `questions[].optionLayout`. DB: `POPUP_QUESTION.OPTION_LAYOUT`. `VERTICAL`(기본), `HORIZONTAL`. 누락 시 세로형, 서버는 미지원 값 거절.
- 적용 범위: SURVEY/QUIZ의 각 선택형 문항. 한 팝업에서 가로·세로 혼합 가능. 주관식에는 적용하지 않으며 문항 템플릿 저장·불러오기 시 유지된다.
- 가로형: 왼쪽부터 배치하고 너비를 넘으면 다음 줄로 이어진다. 긴 문구와 공백 없는 문자열도 영역 안에서 줄바꿈한다.
- 기존 RATING5: 2026-09-28(설계 18 L-4)에 유형을 삭제했다. 기존 문항은 DB 08 스크립트로 SINGLE_CHOICE + 가로 배치로 이관한다(보기가 없으면 1~5 생성).

## 데모 모드

저장소 루트에서 최신 소스를 실행한다. 기존 `dist/Popup.exe`는 별도 게시 전까지 이전 버전이다.

```powershell
dotnet run --project popup-frameWork/Popup/Popup.csproj -- --demo
```

1. 왼쪽에서 **1번 문항 선택지 배치**는 세로형, **2번 문항 선택지 배치**는 가로형으로 선택하고 **설문 팝업**을 연다.
2. 1번 보기는 세로, 2번 보기는 가로로 배치되는지 확인한다. 첫 문항에는 짧은 보기, 긴 문장, 공백 없는 영문·숫자 보기가 있다.
3. 팝업을 닫고 1번은 가로형, 2번은 세로형으로 바꿔 다시 연다. 짧은 보기들은 나란히 배치되고 긴 보기와 다음 항목은 영역 너비에 맞춰 줄바꿈되는지 확인한다.
4. 필수 문항 두 개에 응답하고 제출한다. 결과 로그에서 선택한 optionId/value 전송과 ACCEPTED를 확인한다.
5. 제출 완료 후 다시 테스트하려면 **서버 상태 초기화(숨김·완료)**를 누른다. 배치 변경만으로 완료 상태가 초기화되지는 않는다.
6. **퀴즈 팝업**에서도 두 배치를 확인한다. 두 번째 문항은 복수 선택이며 긴 보기를 포함한다. 정답은 첫 문항 **휴대전화 번호**, 두 번째 문항 **충분히 긴 비밀번호 사용 + 다중 인증 사용**이다. 모두 맞히면 100점/통과다.

배치 선택은 다음에 여는 설문·퀴즈에 적용되며 전체 팝업 순차 실행에도 적용된다. 데모 결과는 실제 서버·DB에 저장하지 않는다.

## 등록 페이지 미리보기

1. SURVEY 또는 QUIZ의 단일/복수 선택 문항에 짧은 보기 여러 개와 긴 문장, 공백 없는 문자열을 입력한다.
2. 첫 문항을 가로형, 두 번째 문항을 세로형으로 지정하고 미리보기 폭을 줄인다. 항목이 오른쪽 밖으로 빠지지 않고 다음 줄로 이어지는지 확인한다.
3. 첫 문항만 세로형으로 바꾸어 두 번째 문항의 설정에 영향이 없는지 확인한다. 긴 보기 자체는 여러 줄이 될 수 있다.
4. 저장 후 다시 열거나 템플릿을 불러와 각 문항의 배치 설정이 유지되는지 확인한다. 연결된 서버에서 받은 WPF 팝업에도 동일한 배치가 적용되는지 확인한다.

## 검증 기록 (2026-09-28)

웹 타입 검사·WPF 빌드 통과. 서버 관련 테스트 23건 통과, 실DB 테스트 1건은 접속 정보 부재로 생략. 데모 DTO를 실제 PopupFactory에 전달해 설문·퀴즈 × 1번/2번 문항별 가로·세로 조합 × 폭 400/620/900에서 393개 레이아웃 검사 통과. 창을 띄우지 않은 Measure/Arrange 검증이며 버튼 클릭·제출과 실제 DB 저장 왕복은 미실행.

## 저장 방식

배치는 문항 자체의 속성으로 취급한다. DB 컬럼 방식으로 문항 추가·삭제·순서 변경과 템플릿 복사 시 함께 관리한다. content에 문항 ID별 별도 매핑을 두지 않는다. 실제 API는 최상위 questions[].optionLayout을 사용하고, 구형 데모의 content.questions[].optionLayout도 같은 문항 DTO로 읽는다.

## 기존 DB 적용

서버 배포 전 POPUP 소유 계정으로 `db/oracle/archive/05_question_option_layout_oracle.sql`을 한 번 실행한다. 기존 문항은 VERTICAL로 채워진다. 신규 DB는 초기 스키마에 포함되어 있으므로 추가 SQL을 실행하지 않는다. 로컬 XE·원격 개발 DB는 2026-09-28 적용 완료.
