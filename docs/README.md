# 팝업 프로젝트 문서

프로젝트 문서는 저장소 루트의 `docs/`에서 관리한다.

| 위치 | 내용 |
|---|---|
| [design/](design) | 설계 기준·기능별 TODO·구현 및 확인 상태 |
| [interfaces/](interfaces) | API 계약·JSON 예제·Word/PDF 정의서 |
| [reviews/](reviews) | 구현 검토·성능 측정 절차·커밋 분류 기록 |
| [POPUP_OPTION_GUIDE.md](POPUP_OPTION_GUIDE.md) | WPF·서버·관리자 웹 옵션 및 연동 |
| [POPUP_USER_OPTION_GUIDE.md](POPUP_USER_OPTION_GUIDE.md) | 화면에서 사용하는 옵션 설명 |
| [POPUP_ADMIN_UI_GAP.md](POPUP_ADMIN_UI_GAP.md) | 관리자 화면과 계약의 차이 및 보완 항목 |
| [OPTION_LAYOUT_DEMO.md](OPTION_LAYOUT_DEMO.md) | 선택지 배치·줄바꿈 Demo 확인 |
| [FOOTER_LINK_VIDEO_QUIZ.md](FOOTER_LINK_VIDEO_QUIZ.md) | Footer 링크 및 VIDEO+QUIZ 계약 |

현행 API 기준은 [인터페이스 정의서](interfaces/POPUP_INTERFACE_SPEC.md)이며,
변경 이력은 [저장소 CHANGELOG](../version-history/CHANGELOG.md)에 기록한다.
저장소 루트의 [README](../README.md)와 WPF [실행 가이드](../popup-frameWork/README.md)를 함께 참고한다.

문서 이동 이전의 CHANGELOG·커밋 검토 표 경로는 당시 기록이다. 과거
`popup-frameWork/Popup/Docs/`의 옵션 가이드는 현재 이 폴더에 있다.
