# 저사양 PC / Horizon VIDEO 측정

## 실행

대상 PC에 최신 popupSample 빌드와 `scripts/measure-popup-performance.ps1`을 복사한다.
일반 팝업으로 VIDEO를 실행한 뒤 별도 PowerShell에서 아래 명령을 실행한다.
관리자 권한이나 외부 패키지는 필요하지 않다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\measure-popup-performance.ps1 -Phase playing -DurationSeconds 60
```

스크립트는 실행 중인 popupSample 한 개를 자동 선택한다. 여러 개라면 `-PopupProcessId 1234`로 선택한다.
앱을 실행하거나 종료하지 않으며 코어 수·우선순위·그래픽 설정을 변경하지 않는다.
기본 결과 폴더는 `%TEMP%\PopupPerformance`이다. `-OutputDirectory .\results`로 지정할 수 있다.

## 구간별 순서

각 구간의 상태를 먼저 만든 뒤 동일 명령의 `-Phase`만 바꿔 60초씩 측정한다.
영상은 측정 도중 끝나지 않는 동일 파일·동일 크기로 맞추고 최초 로딩 이후 측정한다.

| Phase | 화면 동작 | 별도로 기록할 사항 |
|---|---|---|
| idle | VIDEO 팝업을 닫고 Demo 화면에서 대기 | 앱 기본 CPU |
| playing | 일반 VIDEO를 연속 재생 | 영상 해상도·엔진(MediaElement / WebView2) |
| paused | 같은 영상 일시정지 | 로딩 표시가 남는지 |
| dragging | 영상 재생 중 같은 모니터 안에서 반복 드래그 | 네 모서리 빈틈·돌출·추적 지연 |
| dpi-move | 영상 재생 중 배율이 다른 모니터 간 양방향 이동 | 100↔125%, 100↔150%, 125↔150% |
| fullscreen | 영상 내부 전체화면 재생 | 전체화면 위에 모서리가 남는지 |

VIDEO+QUIZ에서도 playing·dragging·fullscreen을 반복한다. 같은 조건을 3회 측정하고
이전 빌드와 수정 빌드를 같은 PC·영상·창 크기·원격 접속 조건으로 비교한다.
검은색·밝은색 배경에서 모서리를 각각 확인한다. 드래그 시작·이동 중·종료 후를 모두 확인한다.
모니터가 하나뿐이면 dpi-move는 미실행으로 기록한다.

## 결과 해석

- `samples.csv`: 실제 샘플 간격, 앱 본체 CPU, 자손 포함 CPU, 메모리, 프로세스 수.
- `summary.json`: 시간 가중 평균 CPU·최대 CPU와 메모리 최대값.
- `environment.json`: CPU·논리 코어 수·RAM·OS·세션·실행 파일 경로·측정 조건.

CPU는 전체 논리 CPU 용량을 100%로 계산한다. WebView2 자손까지 포함한 treeCpuPercent를
함께 비교해야 브라우저로 이동한 부하를 놓치지 않는다. 공유 페이지 때문에 자손 WorkingSet
합계는 실제 물리 메모리 사용량보다 클 수 있다. CPU는 샘플 간 평균으로 짧은 피크는 숨겨질 수 있다.
측정 도구 자체의 프로세스 조회 부하가 있으므로 두 빌드 모두 같은 간격으로 측정한다.
원격 화면 전송 프로세스·DWM·시스템 전체 CPU, UI 지연, 모서리 품질은 자동 측정 대상이 아니다.
작업 관리자 시스템 CPU와 육안 결과를 아래 표에 별도로 적는다.

| PC / 빌드 / 구간 | 앱 평균 / 최대 CPU | 자손 포함 평균 / 최대 CPU | 시스템 CPU | 모서리·DPI·전체화면 결과 |
|---|---|---|---|---|
| | | | | |

기존 불투명 창에서 관찰된 약 10% CPU는 특정 환경의 참고값이며 모든 PC의 합격 기준이 아니다.
동일 PC에서 이전 불투명 빌드 대비 재생 부하 증가 여부와 모서리 결함을 함께 판단한다.
로컬 코어 제한은 CPU 여유 감소만 모사하므로 Horizon·GPU·원격 전송·DPI 실측을 대신하지 못한다.
현재 이 가이드 작성만으로 저사양 PC 검증이 완료된 것은 아니다.
