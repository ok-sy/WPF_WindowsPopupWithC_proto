## 1. 확정된 결정 요약

| 분류 | 결정 | 상세 근거 |
|---|---|---|
| **C 폐기·대체** | 3111 백엔드 전달용 샘플의 우리 쪽 활성 개발 제외, MSI offline-export 폐기, pnpm store 설치 경로→node_modules 복사 방식 대체, 구 목록 API/디스크 결과 큐/분리 HWND 등 후속 대체 | [1단계](20261103_활성작업_폐기대체_정리_검토.md) |
| **C 종료 기능** | 상시 실행 WPF의 일반 사용자용 `--exit` 및 `--tray` 종료 메뉴 신규 개발 제외. 기존 OS 종료/로그오프·운영 종료 대응은 유지 | [3단계 §8](20261103_활성작업_A실행판단_검토.md) |
| **D 상태 정정** | 이미 구현된 항목은 증거가 있는 범위만 체크, 구 정책은 대체 표시. 실화면 미실행을 완료로 표시하지 않음 | [2단계](20261103_활성작업_D상태대조_검토.md) · [3단계 §7](20261103_활성작업_A실행판단_검토.md) |
| **A 실행** | 56-8 검사→D 정정→pickPopupFields 하네스→PU001 정적 추적→메모리 결과 큐→WPF 백그라운드/트레이 순 | [3단계 §3](20261103_활성작업_A실행판단_검토.md) |
| **자동 시작** | 최초 **사용자 세션** 실행 시 HKCU 1회 등록, 사용자가 해제하면 다시 강제 등록하지 않음 | [3단계 §6·8](20261103_활성작업_A실행판단_검토.md) |
| **배포** | 보안팀 소프트웨어 매니저 사용 가능성은 **미확정**. R1의 로컬 서버+원격 개발 DB 검증을 원격 서버 배포 완료로 취급하지 않음 | [3단계 §2·6](20261103_활성작업_A실행판단_검토.md) |

## 2. 환경별 검증 회차

| 회차 | 범위 | 선행 |
|---|---|---|
| **R1** | 로컬 Spring + 원격 개발 Oracle DB + Windows WPF + 로컬 관리자 웹. 등록·조회·표시·결과 전송·재조회 | 메모리 결과 큐 전환 및 단위 검증 후, 테스트 계정·DB 변경 범위 확인 |
| **R2** | 폐쇄망 실제 SSO·토큰·백엔드 연계·실서버 | API 계약·접속·배포 정보 수신 |
| **R3** | 저사양 PC·Horizon·DPI·멀티 모니터·VIDEO | 장비·측정 파일 확보 |
| **R4** | 폐쇄망 FRONT/WPF/Oracle 반입·재부팅 자동 시작·폰트/모듈 | 반입 환경과 배포 운영 방식 확인 |

## 3. 미확정·외부 대기

- **B 정책:** 결과 큐 장애 처리 세부 규칙, 동일 resultId 다른 본문 판정, 다중 PC·전달 보존, 영수증 D5, PU001 Q3 관련 정의. [ACTIVE_TASKS B](../policies/ACTIVE_TASKS.md#b-정책-정의-필요-결정-없이-임의-변경-금지) 참조.
- **외부 입력:** 사내 SSO/토큰 계약, 실제 URL·코드표·DB 저장 루트, 기획서 원본, 로고, 저사양 PC, 보안팀 배포·라이선스 검토.
- **새 화면설계서:** [recieve_plan0.5](../design/recieve_plan0.5.md)에서 P01~P06 수신 기준을 관리. 2026-11-02 기존 요구사항 TODO는 이력·실행 추적으로 유지.
