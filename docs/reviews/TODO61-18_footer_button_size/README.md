# TODO61-18 푸터 버튼·푸터 높이 비교 이미지

작성일 2026-11-18 · 원본 TODO: [61-18](../../design/61_관리자_미리보기_컴포넌트화_TODO.md)

푸터 버튼 높이와 푸터 높이를 정하기 위해 실제 WPF `PopupWindow`(Demo 데이터, 96 DPI 기준 2배 해상도)를 그려 비교한 이미지다. 관리자 미리보기는 같은 값으로 맞춰 따로 캡처하지 않았다.

## 결정

- 푸터 버튼(나중에 보기·보조 닫기·확인·바로가기·제출, 본문 제출 영역 포함) 높이 **34**. 너비 하한(118, 제출 132)·색·모서리는 기존 유지.
- 푸터 높이 **64**(기존 80), 버튼 위아래 여백 **15**씩(기존 위 19·아래 27).
- 진행 문구가 붙는 설문·퀴즈·VIDEO+QUIZ·VIDEO 푸터는 자동 높이, 최소 64.
- 결과 안내창(`PopupAlert`)의 버튼은 높이 44 그대로.

## 참고: 크기 실측(같은 데이터, 웹·WPF 동일)

| 버튼 | 크기 |
|---|---|
| 나중에 보기 | 120.9 × 34 |
| 확인·바로가기 | 118 × 34 |
| 제출 | 132 × 34 |

'나중에 보기'는 실제로 '확인'보다 2.9 넓지만 연회색 면·옅은 테두리라 진한 '확인'보다 작아 보일 수 있다(대비에 의한 착시). 설문 '제출'은 최소 너비 132라 실제로 11 넓다.
