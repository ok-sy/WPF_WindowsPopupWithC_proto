## 확정 계약

외부 크기 입력은 공통 `popup.width / popup.height` 한 쌍을 사용한다. IMAGE에서는 `content.imageSizeMode`에 따라 이 값의 해석이 달라진다. `content.width / content.height`는 제거 대상으로 지정한다. 다른 팝업 유형의 공통 크기 의미는 유지한다.

| 모드 | width / height 의미 | 영역 계산 | 이미지 표시 |
|---|---|---|---|
| ADAPTIVE | 팝업 창 전체 크기 | 창에서 표시 중인 헤더·푸터·설명·여백을 제외해 이미지 영역 할당 | 배정 영역에 비율 유지하며 맞춤 |
| FIT_TO_IMAGE | 이미지 콘텐츠 영역 크기 | 지정 콘텐츠 영역을 먼저 확보한 뒤 헤더·푸터·설명·여백을 추가해 창 계산 | 기존 keepAspectRatio 비율 고정/해제 규칙 유지 |
| ORIGINAL | 팝업 창 전체 크기 | 창에서 헤더·푸터·설명·여백을 제외해 이미지 영역 할당 | 원본 크기로 배치, 넘치는 부분 잘림(overflow hidden에 해당하는 WPF 클리핑) |

- FIT_TO_IMAGE의 창 크기는 지정 콘텐츠 크기에 부가 영역을 더해 계산한다. “기준 창보다 원본 이미지가 크면 창을 확장한다”는 규칙은 채택하지 않는다.
- 같은 600×400이라도 ADAPTIVE/ORIGINAL은 창 전체가 해당 크기이고, FIT_TO_IMAGE는 이미지 콘텐츠 영역이 해당 크기다(최소·최대 제한 적용 전).
- 콘텐츠 영역은 이미지가 배치되는 공간이다. 비율 유지 시 실제 이미지가 차지하는 크기는 원본 종횡비에 따라 작아지고 여백이 생길 수 있다.
- FIT_TO_IMAGE에서 설명을 표시하면 설명은 지정 이미지 콘텐츠 영역을 침범하지 않도록 추가 공간으로 계산한다.
- 최소·최대 창 제한은 유지한다. FIT_TO_IMAGE는 최소 크기 미달 시 창 여백을 허용하고, 최대 크기를 넘으면 창을 제한하고 넘치는 콘텐츠를 자른다. 최대 제한을 이유로 이미지를 임의 자동 축소하지 않는다.
- ORIGINAL은 창을 원본 이미지 크기로 확대하지 않는다. 원본 크기 해석(DPI 포함)은 기존 WPF 표시 규칙을 확인·유지한다.
- FULLSCREEN은 공통 sizeMode이며 imageSizeMode에 합치지 않는다. 기존 조합/우선순위는 조사 후 문서에 명시하고 이번 변경으로 임의 재정의하지 않는다.

## 등록 화면 표시 기준

| 모드 | 입력 라벨 | 도움말 |
|---|---|---|
| ADAPTIVE | 팝업 너비 / 팝업 높이 | 창 전체 크기입니다. 이미지는 헤더·푸터·설명 등을 제외한 영역에 맞춰 표시됩니다. |
| FIT_TO_IMAGE | 콘텐츠 너비 / 콘텐츠 높이 | 이미지 영역 크기입니다. 헤더·푸터·설명 공간이 추가되어 실제 창은 더 커질 수 있습니다. 최대 창 크기를 넘는 부분은 잘립니다. |
| ORIGINAL | 팝업 너비 / 팝업 높이 | 창 전체 크기입니다. 이미지는 남은 영역에 원본 크기로 표시되며 넘치는 부분은 잘립니다. |

입력란 아래 도움말을 기본으로 제공한다. 필요한 경우 도움말 레이어 또는 영역별 미리보기로 창 전체/헤더/이미지/설명/푸터의 관계를 설명한다. 안내 문구를 실제 팝업의 content.description에 저장하지 않는다.

### 58-4 FIT_TO_IMAGE 콘텐츠 기준 처리

- [ ] 헤더·푸터·설명 높이와 공통 여백을 한 번만 더한다. 공통 창 크기를 먼저 고정해 콘텐츠가 줄어드는 이중 적용을 방지한다.
- [ ] keepAspectRatio true/false의 기존 의미를 보존한다. 콘텐츠 영역 크기와 비율 유지 후 실제 이미지 크기를 구분한다.

- [ ] 최대 크기 초과는 클리핑으로 처리하며 원본 이미지 크기를 기준으로 새 확장 규칙을 만들지 않는다.
