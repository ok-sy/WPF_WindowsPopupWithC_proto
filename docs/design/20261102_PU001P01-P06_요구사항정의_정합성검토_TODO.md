## 1. 목적과 범위

- 사용자 승인 Q1~Q7을 **요구사항 기준선**으로 고정하고, PPT 표시 동작·현재 proto 구현·관리자 웹/서버 계약의 정합성을 판단한다.
- 구현이 이미 존재한다는 사실과 실제 화면이 기획서대로 표시된다는 사실은 다르므로 **정적 일치**, **부분 일치**, **미확인**, **충돌(승인 정책이 우선)**로 구분한다.
- 기획서에 없는 문구·크기·옵션 기본값·API 필드는 만들어 내지 않는다.
- 코드·DTO·DB·정책 값은 이 문서 작성 단계에서 수정하지 않는다.

## 4. 현재 proto 정적 정합성 판정

판정 기준: **일치** = 코드상 승인 조건의 직접 구현 확인; **부분 일치** = 기본 동작은 있으나 기획 화면의 세부 정책/문구는 확인 필요; **미검증** = 장치/실화면 실행하지 않음. 실화면 검증을 정적 판정에 포함하지 않는다.

| 항목 | 판정 | 근거 / 남은 검토 |
| --- | --- | --- |
| Q1 VIDEO 완료 조건 | **일치(정적)** | `docs/policies/POL-05.md`의 누적 시청 완료 기준, `PopupOptions.CompletionRatio`, `PopupWindow.RefreshFooterState()`. 실제 영상 종료·재생 실패 실험은 미검증 |
| Q2 QUIZ 제출·채점 | **일치(정적)** | `SurveyPopupView.UpdateResponseProgress()`의 `CanSubmit`; `Submit()`의 제출 시 채점, `QuizGrader` |
| Q3 참여형/만점형 | **부분 일치** | `passingScore`·미통과 처리 기반 존재. 그러나 기획서의 두 모드가 정확히 어떤 점수/안내/종료 예외에 대응하는지는 별도 정의 필요. `QuizGrader`는 누락·비양수 `passingScore`를 0으로 취급하므로 '참여형' 의미로 자동 단정하지 않음 |
| Q4 SURVEY 필수 검증 | **일치(정적)** | `SurveyPopupView.UpdateResponseProgress()`: `CanSubmit = IsEnabled && completed == required && belowMinimum < 0`, 제출 비활성 사유·접근성 안내 |
| Q5 VIDEO+QUIZ 잠금 | **일치(정적)** | `VideoQuizPopupView.cs`: 초기 `Quiz.IsEnabled=false`; `VideoCompletion.IsReached()` 후 `Unlock()`으로 true |
| Q6 나중에 보기 | **일치(정적, 표시 조건)** | `PopupOptions.ShowLater`, `PopupFactory.ShowLater = popupDto.ShowLater`, `PopupWindow`의 푸터 표시 조건. 실제 서버 옵션 공급·재노출 일정은 별도 검증 |
| Q7 TEXT·IMAGE 스크롤 | **부분 일치** | 승인한 '스크롤 완료 요구 없음'과 공통 푸터 정책 일치 예상. TEXT/IMAGE 화면의 스크롤·확인 기능 간 실제 연결을 이벤트·실화면에서 추가 대조해야 함 |
| 공통 헤더·푸터 | **부분 일치** | `PopupOptions.ShowHeader/ShowFooter/ShowFooterButton/FooterAction` 지원. 기획서의 버튼 배치/레이블/고정 영역은 실화면 대조 필요 |
| 결과·안내 UI | **부분 일치** | 제출/닫기/나중에 보기 결과 경로 존재. 기획서 Alert 문구·참여형/만점형 안내 정확한 일치 여부는 확인 필요 |

**정합성 판단:** 승인한 Q1~Q7과 정면 충돌하는 코드 변경 필수 항목은 정적 범위에서 발견되지 않았다. 그러나 **기획서와 100% 일치·검증 완료를 뜻하지 않는다.** 특히 Q3와 화면 배치/문구/예외는 유보.

## 4-1. 호출 경로 정적 추적 결과 (2026-11-03)

코드 정적 읽기만 수행했다. 실행·실화면·실DB 검증이 아니다. 코드 변경 없음.

| 범위 | 판정 | 근거 요약 |
| --- | --- | --- |
| P1-1 푸터·확인·닫기·나중에 보기 | **일치(정적)** | 활성 판정은 `PopupWindow.RefreshFooterState`(`PopupWindow.xaml.cs:1148-1200`) 한 곳. TEXT/IMAGE는 분기 없이 확인 항상 활성, 스크롤 이벤트 사용 0건(Q7). 확인 → `CloseButton_Click`(`:924`) → SURVEY/QUIZ는 `Submit()`, 그 외 `CloseByApp` → `PopupManager` Closing → `PopupResultBuilder.BuildOnClose`(LATER > HIDDEN > VIDEO_WATCHED > CLOSED, `PopupResultBuilder.cs:123-171`) → `PopupResultQueue.Enqueue`(저장 실패 시 닫기 취소). 상단 X 없음, Esc 무동작, Alt+F4는 Overlay 켜짐 + 화면에 나가는 수단이 있을 때 차단, Overlay 클릭은 앞으로 가져오기만. 나중에 보기는 `ShowFooter && ShowLater`(`:347-351`)이고 완료 기준과 무관하게 누를 수 있음 |
| P1-2 QuizGrader | **일치(정적, Q3 정의 제외)** | 정답 ID 집합 완전 일치(부분 점수 없음), 배점 null → 1점, passingScore null·0 이하 → 0(항상 통과, `QuizGrader.cs:46`). 불합격: 모달 "다시 도전해 주세요"/"답안 수정", 창·답안 유지, 결과 미전송, 재제출 횟수 제한 없음, Overlay 꺼짐이면 이후 보조 닫기 표시(`PopupManager.cs:260-265`, `PopupWindow.xaml.cs:1125-1131`). 합격: SUBMITTED(score·passed) 저장 → "평가를 통과했어요" → 닫힘 |
| P1-3 VideoCompletion | **일치(정적)** | VIDEO 확인 활성과 VIDEO+QUIZ 해제가 같은 `VideoCompletion.IsReached` 사용. 기준 null → 1.0(`PopupFactory.cs:58·95`). VIDEO는 매번 재계산, VIDEO+QUIZ는 한 번 해제되면 유지. 재생 실패: VIDEO는 확인 활성, VIDEO+QUIZ는 퀴즈 잠금 유지·보조 닫기만 |
| P1-4 관리자 웹 미리보기 | **부분 일치** | 미리보기가 시청 비율 슬라이더·퀴즈 잠금·로컬 채점·필수/최소 선택·`showFooter && showLater`를 직접 재현(`PopupPreview.tsx`). 차이: 독립 샘플·가이드 화면의 `withPreviewFallback`은 VIDEO+QUIZ `completionRatio` 미설정을 0.8로 그리나 서버·WPF는 1.0(`popupPreviewFallback.ts:39`). RgstPop은 fallback 미사용이라 영향 없음. 재생 실패 보조 닫기는 의도적으로 미재현 |
| P1-5 서버 전달·결과 처리 | **부분 일치** | 운영 경로 `SHOW_LATER_YN`·`COMPLETION_RATIO`·`PASSING_SCORE` → `WpfPopupItem`(passingScore는 QUIZ만, null 키 생략) → WPF DTO 이름·타입 일치. QUIZ 저장 시 passingScore null 거부. 결과 `resultType` 처리: LATER는 완료 아님 + 폴링 주기 유예 후 재노출, VIDEO+QUIZ 제출은 서버가 시청 완료 재확인. **서버는 QUIZ를 다시 채점하지만 불일치 시 경고 로그만 남기고 WPF의 score·passed로 저장**(`PopupService.java:612-620`) |

### 확인된 차이·결정 필요 (B 후보, 코드 미수정)

1. 서버 채점 신뢰: 클라이언트 `passed`를 그대로 저장하고 `passed == (score >= passingScore)` 일관성도 보지 않음. 서버 판정 기준으로 바꿀지 결정 필요.
2. Q3 연결: passingScore 미설정(null·0 이하)이면 WPF·서버 모두 항상 통과. 운영 저장은 null을 거부하지만 3117·3111 샘플 경로는 QUIZ passingScore null이 남을 수 있음.
3. QUIZ 불합격 뒤 '보지 않기' 체크 + 보조 닫기/Alt+F4로 나가면 통과 없이 HIDDEN 기록 가능.
4. 서버 제출 검증에 SURVEY 최소·최대 선택 수 검사 없음(WPF·웹만 막음).
5. 서버는 LATER 수신 시 팝업 `showLater` 설정을 확인하지 않음(인터페이스 명세에 기록된 의도).
6. VIDEO+QUIZ 재생 실패 시 퀴즈 진행 불가·닫기만 허용이 Q1 "재생 오류 기존 예외" 범위인지 확인.
7. 웹 미리보기 fallback 0.8(독립 샘플·가이드) ↔ 실제 1.0.
8. `docs/interfaces/WPF_POPUP_MINIMAL_SPEC.md`: ShowLater 행 없음, 128행 "QuestionScore 누락이면 0점"은 코드·ALL_SPEC(1점)과 다름, 132행 TEXT 자동 채점 제외는 최초 범위 정의라 유지 여부 확인. 최소 범위 계약 문서라 임의 수정하지 않음.
