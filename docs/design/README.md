# 설계·TODO 기능 목차 (F100~F300)

기준일: 2026-11-17 (KST, [TODO78](78_기능정책_F_P_문서체계_정리_TODO.md)).

`docs/design/`의 원본 TODO·설계 문서를 **기능 대단위(F)** 로 묶은 목차다. 새 번호는 대단위에만 붙이고, 세부 작업은 기존 TODO 번호·파일명·체크박스로 관리한다. 원본 파일은 이동하거나 이름을 바꾸지 않으며 기존 TODO 번호, `POL-xx-yy`, 문서 경로·앵커, 코드 주석, 변경 이력은 그대로 원본 참조로 쓴다.

- 진행 상태(대기·진행·완료)와 다음 할 일은 [활성 작업](../policies/ACTIVE_TASKS.md) 한 곳에서 관리한다. 이 목차에는 상태를 중복해 적지 않고, 폐기·대체만 표시한다.
- API 계약·오류·배포처럼 정책 성격이 강한 원본은 아래 [정책 성격 원본](#정책-성격-원본-p100p400)에 두고 [정책 목차](../policies/README.md#정책-대단위-목차-p100p400)의 P 대단위와 연결한다.
- 한 원본이 여러 대단위에 걸치면 주된 곳 하나에만 두고 비고에 관련 대단위를 적는다.

| 번호 | 영역 | 범위 |
|---|---|---|
| F100 | WPF 팝업 | 표시·종료·영상·설문·퀴즈·VM 복귀 |
| F200 | 관리자 웹 | 등록·편집·미리보기·탭 |
| F300 | 개발 도구 | API Demo·샘플·로컬 검증 도구 |
