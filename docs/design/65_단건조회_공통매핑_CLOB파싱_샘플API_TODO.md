## 확정 범위

단건 조회 SQL → 공통 헤더/옵션(popupHeader 역할) 구성 → 콘텐츠 CLOB JSON 파싱 → 선택 옵션 기본값 적용 → 기존 WPF 단건 조회 응답 조립까지를 샘플 API로 제공한다. popupHeader라는 별도 JSON 필드를 새로 도입한다는 뜻은 아니며, 실제 출력 필드명·위치는 기존 WPF 계약을 따른다.

실제 대상자·게시 일정·완료·숨김·나중에 보기 후보 판단, 전달 건 생성/재사용·소유권·중복 처리 등 업무 로직은 서버 담당자의 구현 책임으로 표시한다. 기존 구현을 제거하거나 이미 확정된 정책을 바꾸는 작업이 아니다.
