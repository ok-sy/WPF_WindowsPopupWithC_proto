# 78. 기능·정책 문서 체계 정리

상태 · 대기

## 확정 사항

문서의 진입점을 기능과 정책으로 나눈다. 새 번호는 대단위에만 부여한다. 세부 작업은 대단위 아래에서 제목과 체크박스로 관리한다.

| 번호 | 영역 | 범위 |
|---|---|---|
| F100 | WPF 팝업 | 표시·종료·영상·설문·퀴즈·VM 복귀 |
| F200 | 관리자 웹 | 등록·편집·미리보기·탭 |
| F300 | 개발 도구 | API Demo·샘플·로컬 검증 도구 |
| P100 | 화면·콘텐츠 | 표시 기본값·입력·완료 조건 |
| P200 | API·데이터 | 조회·결과 계약·전달 건·중복 처리 |
| P300 | 오류·복구 | 오류 판정·재시도·결과 큐·오류 응답 기준 |
| P400 | 실행·배포 | 빌드·설정·자동 시작·폐쇄망 반입 |

활성 작업은 **대기 → 진행 → 완료**로 관리한다. 결정, 구현, 폐쇄망 검증 등 남은 행동은 **다음 할 일**에 적는다. 완료 기준에 필요한 검증을 끝낸 항목만 완료로 표시한다. 폐기·대체 항목은 이력에 남긴다.
