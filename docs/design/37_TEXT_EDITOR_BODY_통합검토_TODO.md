## 범위

TEXT 편집 본문에서 제목·설명 역할까지 표현할 수 있으므로, TEXT의 content 안에 있는 별도 제목·설명 영역을 편집 본문으로 통합할지 검토한다. 기존 TODO28의 구간별 서식 편집과 별도 결정 사항이다.

- 검토 대상은 **TEXT.content 내부**다.
- 팝업 공통 title(헤더 제목), 단건 조회의 nextPopup 구조, 다른 팝업 유형까지 삭제·통합하는 요건이 아니다.
- BODY는 통합 본문의 개념명이다. API 속성을 body로 신설·변경한다는 결정은 아직 없다.
- textBlocks와 plainText가 같은 본문을 표현하는 현재 관계를 고려한다. 서식 원본과 파생 일반 문자열의 필요성은 별도 제목·설명 필드 유지 여부와 구분한다.
