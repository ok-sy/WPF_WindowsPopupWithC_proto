## 확정 요건

팝업 최소 크기는 가로 300·세로 300으로 설정한다. 관리자 팝업 설정 및 미리보기와 WPF 실제 팝업에 동일한 기준을 적용한다. 웹은 CSS px, WPF는 기존 논리 크기 단위를 기준으로 하며 DPI에서 물리 픽셀 수가 달라질 수 있음을 안내한다.

최소 크기는 팝업 창 전체 기준이다. IMAGE FIT_TO_IMAGE의 width/height는 기존대로 콘텐츠 크기이며 헤더·푸터를 더한 최종 창에서 최소 크기를 판단한다. ADAPTIVE·ORIGINAL의 기존 창 크기 의미도 유지한다. 관리자 화면 전체나 모든 앱 Dialog의 최소 크기를 300으로 바꾸는 범위는 아니다.
