# TODO68 — 팝업 최소 크기 300×300 공통화

## 확정 요건

팝업 최소 크기는 가로 300·세로 300으로 설정한다. 관리자 팝업 설정 및 미리보기와 WPF 실제 팝업에 동일한 기준을 적용한다. 웹은 CSS px, WPF는 기존 논리 크기 단위를 기준으로 하며 DPI에서 물리 픽셀 수가 달라질 수 있음을 안내한다.

최소 크기는 팝업 창 전체 기준이다. IMAGE FIT_TO_IMAGE의 width/height는 기존대로 콘텐츠 크기이며 헤더·푸터를 더한 최종 창에서 최소 크기를 판단한다. ADAPTIVE·ORIGINAL의 기존 창 크기 의미도 유지한다. 관리자 화면 전체나 모든 앱 Dialog의 최소 크기를 300으로 바꾸는 범위는 아니다.

- [ ] 폐쇄망에서는 기존 일괄 조회의 `code0101` 목록을 `applyPopupDefaultCodes()`에 전달하고 적용 완료 시점의 값을 읽는다. 화면별 재조회나 숫자 상수 복제를 피한다.
- [ ] 예를 들어 `WIDTH=650`, `HEIGHT=490`이면 새 폼의 실제 입력값과 최초 저장 요청이 650×490인지 확인한다. 유효한 가로만 있고 세로가 누락된 경우에도 기존 파서가 결정한 값을 축별로 사용한다.
- [ ] 기존 팝업 불러오기는 저장값을 우선한다. 최초 입력 후 재렌더링·유형 전환·공통코드 재조회 시 편집한 값과 직접 지운 빈칸을 보존한다. 조회 지연 중 편집을 시작한 경우에도 같은 기준을 확인한다.
- [ ] IMAGE는 최초 입력 후 기존 높이 자동 계산·원본 크기 맞추기 동작을 확인한다. Git 샘플 검증과 폐쇄망 실제 저장 결과는 각각 기록한다.

#### 구현 전에 결정할 사항

최초 입력값의 출처와 적용 범위는 확정했다. 폐쇄망 이식 시에는 공통코드 조회 완료를 판별하는 스토어 상태를 확인한다.
