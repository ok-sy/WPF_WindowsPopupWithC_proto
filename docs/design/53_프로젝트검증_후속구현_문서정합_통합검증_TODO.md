## 목적과 범위

프로젝트 구조·TODO 반영 점검에서 확인한 문서 불일치, 남은 구현, 정책 결정 및 실제 환경 검증을 연결한다. 기존 TODO를 다시 구현하는 작업 목록이 아니라 남은 작업의 실행 순서와 완료 증거를 관리하는 통합 목록이다. 작업 완료 시 원본 TODO와 이 문서를 함께 갱신한다.

- 대상 환경: 로컬, 개발계/검증계 API, 원격 개발 DB, 접근 가능한 Windows·다중 모니터·저사양 PC·Horizon 테스트 환경.
- **폐쇄망 검증은 제외한다.** `net10.0-windows10.0.17763.0` 대상 WPF 폐쇄망 빌드·의존 패키지 검증은 완료 확인되어 남은 TODO에서 제외한다(2026-10-17 개발자 확인, TODO14 §4.5·§8 반영). 대상 프레임워크 설정은 유지한다. 폐쇄망 패키지 반입, 반입 PC 설치·자동 실행·재부팅·연동 확인도 이 문서의 작업이나 완료 조건에 넣지 않는다.
- 개발 환경에서의 통신 실패·서버 재기동·결과 큐 복구 검증은 포함한다. 이는 폐쇄망 반입 검증과 구분한다.
- TODO17 자동 업데이트와 TODO26 Header/Footer 분리 설계는 폐기 상태를 유지한다. TODO15·29·36 등의 과거 설계는 후속 설계의 대체 관계를 따른다.
- TODO52의 기능 요건은 확정 상태다. 상세 계약 수신과 구현을 진행하며 요건 승인 대기로 되돌리지 않는다. TODO35·45·47의 명시적으로 보류된 정책은 이 문서 등록만으로 확정하지 않는다.
- WPF는 API 계약·표시·결과 전달, 서버는 선정·반복·완료·저장, 관리자 웹은 입력·편집·미리보기를 담당한다. 서버 정책을 WPF에 중복 구현하지 않는다.
