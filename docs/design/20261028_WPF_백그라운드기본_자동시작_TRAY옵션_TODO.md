## 실행 정책

- 기본 실행: 트레이 아이콘과 상주 관리 창 없이 백그라운드에서 조회·결과 재전송 수행. 실제 업무 팝업은 기존 조건에 따라 표시한다.
- 사용자 로그인 시 자동 실행을 기본값으로 한다. PC 부팅 전 서비스 실행과 구분한다.
- 트레이 기능은 삭제하지 않고 선택 기능으로 유지한다. 명령행 --tray로 활성화한다.
- 나머지 실행 설정은 환경변수로 받는다. 기존 설정 키·우선순위와 충돌 여부를 구현 전에 확인한다.
- 제안 우선순위: 명시한 명령행 옵션 > 환경변수 > 기본값. --tray는 환경변수의 false보다 우선한다.
- 아래 환경변수 이름은 신규 제안이며 현재 구현된 키가 아니다.

| 설정 | 제안 환경변수 | 기본값 | 명령행 |
|---|---|---|---|
| 트레이 표시 | WPF_POPUP_TRAY_ENABLED | false | --tray로 true |
| 로그인 시 자동 실행 등록 | WPF_POPUP_AUTOSTART_ENABLED | true | 이번 계획에서 별도 인자 추가 안 함 |
| 기타 연결·인증·조회 설정 | 기존 키 우선 재사용, 미지원 항목만 추가 | 기존 계약 확인 | 기존 옵션과 충돌 확인 |
