# 77. 관리자 웹 메인페이지 버튼으로 연 탭의 닫기 버튼 검증

상태: **저장소 코드 정적 추적 완료(2026-11-16) · 저장소 기준 재현 경로 없음 · 발생 버튼·환경 정보 확인 대기**. 코드 변경 없음.

메인페이지 버튼으로 대상 페이지를 열면 탭은 표시되지만 닫기 버튼이 표시되지 않는 현상이 보고됐다. 발생 버튼·대상 페이지·환경과 원인은 확인이 필요하다.

## 확인할 사항

- [ ] 메인페이지에서 문제가 발생한 버튼으로 신규 탭을 열어 닫기 버튼 표시 여부를 기록한다. 같은 페이지를 메뉴에서도 열 수 있으면 메뉴 진입과 비교한다.
- [x] (저장소 기준) `zero-rule-web`에서 메인페이지 버튼 클릭 처리, 탭 등록·재사용, 닫기 버튼 렌더링 조건을 순서대로 추적한다. 진입 경로별 등록 상태와 고정 탭 여부를 비교한다.
- [ ] 신규 탭과 이미 열린 탭 재선택을 각각 확인한다. 닫을 수 있는 탭은 닫기 버튼으로 정상 제거되고, 메인·고정 탭은 기존 닫기 정책을 따르는지 확인한다.
- 완료 기준은 발생 버튼·재현 조건·원인을 기록하고, 조치 후 동일 경로의 닫기 버튼 표시와 동작 및 메뉴 진입 회귀 여부를 실제 화면에서 확인하는 것이다. 영향 범위는 관리자 웹의 페이지 호출과 탭 처리다.

## 구현 전에 결정할 사항

별도 결정은 없다. 대상 탭의 기대 동작은 기존 고정 탭·일반 탭 정책을 기준으로 확인한다.

## 정적 추적 결과 (2026-11-16, Git `main` 기준)

- **탭 렌더링은 진입 경로와 무관하게 하나다.** `layouts/MainLayout/components/SceneTabs.tsx`가 `sceneManager.observeScenes()`의 모든 장면을 같은 `SceneTab`으로 그리고, 모든 탭에 `onClickDeleteBtn`을 넘긴다. 고정 탭·닫기 불가 플래그는 `IScene`(`scene/types.ts`)에 없다.
- **닫기 버튼은 마우스를 올렸을 때만 보인다.** `SceneTab.tsx`의 스타일이 `.SceneTab-closeButton { display: none }`, `&:hover .SceneTab-closeButton { display: inline-flex }`다. 선택된 탭이어도 마우스를 올리지 않으면 닫기 버튼이 보이지 않는다(메뉴로 연 탭도 같음).
- **탭을 여는 경로는 모두 `SceneManager.addScene()`/`replaceScene()`이다.** 사이드바(`Sidebar.tsx`·`CloseSidebar.tsx`, 같은 URL 탭이 있으면 선택), 상단 페이지 번호 입력(`Topbar.tsx` → `routeByPageKey` → `addScene`), Next 페이지 진입(`PageToScene.tsx`), 자료실 화면 전환(`PdsHome`·`PdsEdit`·`PdsViewDialog`의 `replaceScene`). 어느 경로든 결과 장면은 같은 `SceneTab`으로 표시된다.
- **저장소의 메인페이지(`/clover-main`, `features/CloverMainHome`)에는 다른 페이지를 탭으로 여는 버튼이 없다.** 버튼은 차트 기간 전환·새로고침뿐이며 `sceneManager` 호출이 없다. 메인 탭 자체는 `scene-router.tsx`에서 제목이 빈 문자열(`['/clover-main', '', MainHome]`)이라 페이지 정보(`pageNm`)가 없으면 제목 없는 좁은 탭이 된다.

## 판단

- 저장소 코드로는 "메인페이지 버튼으로 연 탭만 닫기 버튼이 없다"는 경로를 만들 수 없다. 가능성은 (1) 보고된 메인페이지가 저장소에 없는 화면(예: 폐쇄망 메인 화면·다른 담당 영역의 버튼)이라 그 버튼이 `SceneManager`를 거치지 않거나 다른 탭 구현을 쓰는 경우, (2) 닫기 버튼이 원래 마우스를 올릴 때만 보이는 동작을 "표시되지 않음"으로 본 경우다.
- 원인이 확인되지 않아 코드는 변경하지 않는다. 마우스를 올리지 않아도 닫기 버튼을 항상 보이게 할지는 기존 탭 정책 변경이라 별도 결정이 필요하다.

## 확인이 필요한 정보

- [ ] 발생 환경(로컬 / 원격 개발 / 폐쇄망)과 메인페이지 화면 이름·URL, 누른 버튼 이름
- [ ] 열린 탭에 마우스를 올렸을 때 닫기 버튼이 나타나는지, 같은 페이지를 메뉴로 열었을 때와 차이
- [ ] 폐쇄망이면 해당 메인페이지 버튼의 이동 코드(`sceneManager.addScene` 사용 여부)
