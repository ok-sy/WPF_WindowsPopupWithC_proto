# 77. 관리자 웹 메인페이지 버튼으로 연 탭의 닫기 버튼 검증

상태는 재현 및 원인 확인 대기다.

메인페이지 버튼으로 대상 페이지를 열면 탭은 표시되지만 닫기 버튼이 표시되지 않는 현상이 보고됐다. 발생 버튼·대상 페이지·환경과 원인은 확인이 필요하다.

## 확인할 사항

- [ ] 메인페이지에서 문제가 발생한 버튼으로 신규 탭을 열어 닫기 버튼 표시 여부를 기록한다. 같은 페이지를 메뉴에서도 열 수 있으면 메뉴 진입과 비교한다.
- [ ] `zero-rule-web`에서 메인페이지 버튼 클릭 처리, 탭 등록·재사용, 닫기 버튼 렌더링 조건을 순서대로 추적한다. 진입 경로별 등록 상태와 고정 탭 여부를 비교한다.
- [ ] 신규 탭과 이미 열린 탭 재선택을 각각 확인한다. 닫을 수 있는 탭은 닫기 버튼으로 정상 제거되고, 메인·고정 탭은 기존 닫기 정책을 따르는지 확인한다.
- 완료 기준은 발생 버튼·재현 조건·원인을 기록하고, 조치 후 동일 경로의 닫기 버튼 표시와 동작 및 메뉴 진입 회귀 여부를 실제 화면에서 확인하는 것이다. 영향 범위는 관리자 웹의 페이지 호출과 탭 처리다.

## 구현 전에 결정할 사항

별도 결정은 없다. 대상 탭의 기대 동작은 기존 고정 탭·일반 탭 정책을 기준으로 확인한다.
