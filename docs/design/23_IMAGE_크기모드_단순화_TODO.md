## 1. 모드와 입력 계약

일반 IMAGE는 창 우선 ADAPTIVE와 이미지 우선 FIT_TO_IMAGE로 정리하고 FILL은 제거한다.
FULLSCREEN과 ORIGINAL의 기존 역할은 유지한다. FULLSCREEN은 공통 sizeMode이고 ORIGINAL은 content.imageSizeMode이므로 같은 ENUM으로 합치지 않는다.

| 항목 | ADAPTIVE — 창 우선 | FIT_TO_IMAGE — 이미지 우선 |
| --- | --- | --- |
| 외부 크기 필드 | content.width / content.height | content.width / content.height |
| 크기의 의미 | 최종 팝업 창 크기 | 이미지 실제 표시 크기 |
| 창 | 지정 크기를 최소·최대 범위 안에서 유지 | 이미지 + 표시되는 제목·설명·푸터 + 공통 여백으로 계산 |
| 이미지 | 배정된 영역에 원본 비율을 유지하며 맞춤 | 지정한 표시 크기 유지 |
| 비율 옵션 | 별도 노출하지 않음, 비율 유지 | keepAspectRatio로 비율 고정/해제 |
| 최소 창 제한 | 창 크기 보정 | 창만 최소 크기로 확대, 이미지 주변 여백 허용 |
| 최대 창 제한 | 제한된 영역에 이미지 맞춤 | 창만 제한, 넘치는 이미지 부분 잘림. 자동 축소 없음 |

- IMAGE의 두 일반 모드에는 content.width/height 한 쌍만 입력·전송한다. 최상위 width/height와 기존 content.imageWidth/imageHeight를 중복된 크기 지시로 사용하지 않는다.
- 외부 응답은 한 쌍으로 단순화하되, WPF 수신 변환부에서 모드에 따라 내부 창 크기 또는 이미지 크기에 매핑한다. 내부 모델까지 동일 필드로 합칠 필요는 없다.
- 서버 저장 컬럼 통합은 필수가 아니다. 기존 저장 구조에서 새 응답 계약으로 매핑할 수 있다. 다른 팝업 유형의 공통 width/height 의미는 바꾸지 않는다.
- 모드 변경 시 등록 크기 입력의 라벨·미리보기를 함께 전환한다. 같은 숫자를 유지하더라도 창 크기와 이미지 크기라는 의미가 달라짐을 표시한다.
- ORIGINAL은 지정한 고정 영역에 원본을 표시하고 넘치는 부분을 자르는 기존 역할을 유지한다. 이 문서의 비율 옵션을 적용하지 않는다. ORIGINAL의 기존 크기 필드 및 FULLSCREEN과의 조합은 구현 시 기존 계약과 대조한다.

## 2. FIT_TO_IMAGE 비율 고정/해제

content.keepAspectRatio는 FIT_TO_IMAGE 전용이며 생략 기본값은 true다. 별도 stretch ENUM은 외부에 추가하지 않는다.

| 설정 | 등록 화면 | 표시 |
| --- | --- | --- |
| true — 비율 고정 | 한쪽 수정 시 반대쪽을 원본 비율로 계산 | 비율에 맞는 실제 이미지 크기로 표시. 빈 사각형에 이미지를 맞추는 방식으로 처리하지 않음 |
| false — 비율 해제 | 너비·높이를 각각 입력 | 두 값을 그대로 사용. 원본 비율과 다르면 이미지가 늘어나거나 눌림 |

- 고정에서 한쪽만 지정하면 원본 비율로 반대쪽 계산. 둘 다 없으면 원본 WPF DIP 크기 사용.
- 해제에서 두 값을 지정하면 그대로 표시한다. 최대 창 제한은 이 표시 크기를 줄이지 않는다.
- 해제에서 미지정 축은 원본 DIP 길이를 사용하는 것을 구현 기준으로 한다. 둘 다 없으면 원본 크기다. 등록 화면에는 최종 계산값을 미리 보여준다.
- true인데 양쪽 값이 원본 비율과 맞지 않는 API 입력은 조용히 왜곡하거나 내부 여백을 만들지 않도록 정규화/거부 기준 및 반올림 허용오차를 구현 전에 명시한다. 서버가 원본을 읽을 수 있는지도 확인하며, WPF에서 원본 로딩 후에도 일관되게 처리한다.
- WPF의 Uniform/Fill은 내부 구현 수단이다. 고정은 원본 비율로 계산한 영역에 Uniform, 해제는 지정 영역에 Fill을 적용할 수 있다.
- UniformToFill 방식의 잘라 채우기 기능은 추가하지 않는다. 최대 창 크기로 인한 Clip과 구분한다.

아래는 IMAGE content의 관련 필드만 발췌한 새 계약 예시다. 전체 API 응답 예시는 구현 시 갱신한다.

```json
{
  "content": {
    "imageSizeMode": "ADAPTIVE",
    "width": 600,
    "height": 400,
    "showDescription": false
  }
}
```

```json
{
  "content": {
    "imageSizeMode": "FIT_TO_IMAGE",
    "width": 600,
    "height": 400,
    "keepAspectRatio": false,
    "showDescription": false
  }
}
```

위 FIT_TO_IMAGE 예시는 원본 비율과 관계없이 이미지 자체를 600×400으로 표시한다. true라면 3:2 원본에 대응하는 크기다.

## 3. 설명과 창 경계

- showDescription으로 설명 표시를 선택한다. OFF 또는 내용이 공백뿐이면 설명 영역과 전용 간격을 함께 제거한다.
- ADAPTIVE/FIT_TO_IMAGE의 설명은 아래로 통일한다. 오른쪽 배치와 세로 이미지 판정에 따른 자동 전환을 제거하고 descriptionPosition 입력·전송을 정리한다.
- 설명은 콘텐츠 가용 너비로 줄바꿈한다. 설명 때문에 창 너비를 임의로 늘리지 않는다. 긴 설명은 제한된 하단 영역에서 세로 스크롤하고 제목·닫기·푸터 조작을 보장한다.
- 최소·최대는 이미지 크기가 아닌 창 크기 제한으로 별도 유지한다. 등록 화면·서버 검증과 WPF 실행 시 방어를 모두 적용한다.
- 최대 창 크기는 설정 최대와 현재 표시 모니터 작업 영역의 안전 범위 중 작은 값이다. 작은 화면에서는 유효 최소가 유효 최대보다 크지 않게 보정한다.
- FIT_TO_IMAGE에서 최소에 걸리면 이미지 크기를 유지하고 여백을 허용한다. 최대에 걸리면 이미지 크기를 유지하고 가용 이미지 영역 밖을 Clip한다.
- FIT_TO_IMAGE의 잘림을 원하지 않으면 원본을 줄여 준비하거나 명시적 표시 크기를 줄인다. 자동으로 전체를 맞추려면 ADAPTIVE를 사용한다.
- 이미지 로딩 전 임시 창 크기, 안전 영역 비율, 잘림 기준점, 설명 높이 배분은 구현 시 명시하고 웹 미리보기와 일치시킨다. ORIGINAL의 기존 잘림 기준점은 유지한다.

## 7. 구현 결정 및 검증 기록 (2026-10-06 KST)

- FIT_TO_IMAGE 고정 상태의 비율 불일치는 너비 우선으로 높이 정규화한다. 편집기 연동값은 소수 둘째 자리로 반올림하되 표시 시 원본 비율을 다시 계산한다. 서버는 원본 URL을 다운로드하지 않는다. 해제의 누락 축은 원본 DIP 길이로 채운다.
- 로딩 전 일반 IMAGE 임시 창은 560×420 DIP. ADAPTIVE의 명시 축은 유지하고 누락 축만 원본과 측정된 콘텐츠에서 산정한다. ADAPTIVE 원본 초과 확대 제한은 유지하며 별도 이미지 상한 입력은 제거했다.
- IMAGE 창 최대는 현재 모니터 작업 영역 너비·높이의 **90%**다. 고정 maximumWidth/maximumHeight 값(기본 1200×900)은 IMAGE 창 상한으로 사용하지 않는다. 최소는 이 화면 상한 이하로 보정하고, 최소로 늘어난 창에는 이미지 주변 여백을 허용한다. content.width/height의 지정 픽셀/DIP 크기는 유지하며 FIT_TO_IMAGE의 최대 초과 부분은 **중앙 기준**으로 자른다. ORIGINAL은 왼쪽 위 Clip을 유지한다. FULLSCREEN은 모니터 전체 크기를 우선한다. 다른 유형의 기존 최대 크기 정책은 유지한다.
