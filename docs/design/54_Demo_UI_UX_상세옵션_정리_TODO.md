### 상세옵션 창에서 확인한 문제
- 그룹이 섞여 있다. `표시 영역·완료 조건`에 헤더/푸터 표시, 다시 보지 않기·숨김 일수·나중에 보기, 완료 조건이 함께 있고, Footer 동작은 `위치·푸터 동작`에 따로 있다.
- 하위 입력이 상위 옵션과 떨어져 있고 적용 여부를 비활성(`IsEnabled`)으로만 표시한다. 숨김 일수는 다시 보지 않기를 꺼도 활성이며, 비활성 사유 안내가 없다.
- `displayMode`(WPF가 읽지 않는 효과 없는 계약 필드, 설계 50-B)와 Demo 전용 `displayOrder`가 첫 그룹에 노출된다.
- 기본값과 변경값 구분, 그룹별 기본값 복원이 없다. 복원은 메인 창의 샘플 전체 복원뿐이다.
- 숫자 범위·단위는 일부 라벨에만 있고 검증은 `설정 적용` 시 맨 아래 오류 한 줄로만 안내한다.
- `콘텐츠` 탭은 DTO 속성 순서 그대로 나열해 관련 항목(예: 하단 안내와 링크, 영상 재생 옵션)이 흩어진다. TEXT 서식 본문은 JSON 직접 편집이다(55와 연결).

### 작은 창 확인
- 최소 크기(820×600)는 물론 기본 크기에서도 API 모드의 주 실행 `팝업 조회`가 왼쪽 패널 스크롤 아래에 있다. 인메모리 모드는 기본 크기에서 실행 버튼이 보인다.
