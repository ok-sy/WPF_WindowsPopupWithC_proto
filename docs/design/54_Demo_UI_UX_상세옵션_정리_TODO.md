## 목적과 범위
Demo 기능 증가에 맞춰 로컬 샘플 편집·팝업 표시와 실제 API 요청·응답 확인의 작업 흐름을 정리한다. 전체 화면 구성뿐 아니라 상세옵션의 분류·조건부 표시·입력·초기화 UX까지 포함한다. 기존 기능은 보존하고 중복 표현과 탐색 부담을 줄인다.
최종 배치·탭 수는 실제 Demo 화면과 사용 흐름을 조사한 뒤 결정한다. 상단 모드 선택, 작업 영역, 요청/응답 영역, 실행·상태 영역은 설계 출발안이며 고정 레이아웃 요구가 아니다.
