## 범위와 기존 과제 구분

원본 카드의 '응답률 계산하지 않음 / 대상자 X / 로깅 X' 개념을 구체화하는 과제다. 기간 내 반복 노출, 창 상시 유지 등 의미는 아직 확정되지 않았다. 기존 단건 API(TODO35)의 완료·미완료 유예 규칙과 별개이며 이번 TODO 추가로 그 구현에 상시 옵션·분기를 넣지 않는다.

이번 반영은 TODO 문서와 카드 관리만 수행한다. 코드 변경·새 DB 적용·환경 배포·테스트 실행은 포함하지 않는다. 원본 카드의 아이디어/보류 표기는 제안 당시 이력이며 현재는 구체화·검토 착수를 진행 확정으로 관리한다. 숫자·필드·정책 선택이 필요한 항목은 아래에서 결정한다.

## 작업 목록

- [ ] 42-1 상시의 의미를 기간 내 반복 노출 또는 창 유지 등으로 구분하고 시작·종료 일시, 게시중단 반영, 재노출 주기를 결정한다.
- [ ] 42-2 대상자 X가 전체 인증 사용자 노출, 대상 그룹 미설정 허용, 대상 목록 집계 미사용 중 무엇인지 명확히 한다. 인증·권한 검증 제거로 해석하지 않는다.
- [ ] 42-3 로깅 X가 응답률·업무 응답 통계 제외인지, 전달 건·재전송·진단 기록까지 제외인지 구분한다. 멱등·중복 방지에 필요한 최소 상태를 검토한다.

- [ ] 42-6 노출 판단은 서버 책임으로 유지하는 방향을 검토하며 후보 조회와 nextStatus 조건을 일치시킨다. 주기·필드·DB 변경은 정책 확정 후 선택한다.
- [ ] 42-7 개념 결정 이후 독립 구현 범위를 작성하고 기존 일반 안내 닫기 완료·미완료 유예 동작과 혼합되지 않는지 검증한다.
