# PU001P01~PU001P06 기획서 × proto 반영·확인 요청

작성: 2026-11-02 (KST)  
원본: 사용자가 전달한 PPT 화면 사진 6장 — 텍스트(103), 이미지(104), 동영상(105), 퀴즈(106), 설문(107), 동영상+퀴즈(108). **사진으로 읽히지 않는 세부 문구와 설계값은 임의 확정하지 않는다.**  
대상: `popup-frameWork` WPF proto. 관리자 웹·서버 계약 변경은 승인 전 금지.

## 적용 원칙

1. 이미 구현된 화면·이벤트·설정은 그대로 재사용한다. 새로운 팝업 유형/DTO를 만들지 않는다.
2. 기획서와 구현이 일치하는 항목은 **현행 사용(코드 변경 없음)**으로 표시한다.
3. 정책 충돌은 임의로 덮어쓰지 않고 확인받은 뒤 WPF·웹 미리보기·서버 계약을 함께 바꾼다.
4. 실제 Windows 기동/시청/제출 검증은 아직 실행하지 않았으며, 본 문서는 정적 소스 대조 결과다.

### 정적 코드에서 확인된 현행 기능

- `popup-frameWork/Popup/Models/PopupOptions.cs`: `ShowLater`, `FooterAction`, `CompletionRatio`, `PopupType` 지원.
- `popup-frameWork/Popup/Views/Contents/SurveyPopupView.xaml.cs`: QUIZ 모드, `passingScore`, 문항별 응답 UI, `ValidateRequiredQuestions()`, `UpdateResponseProgress()`, `CanSubmit`, `SurveySubmitted` 구현.
- `docs/design/43_완료조건_버튼활성화_UX_TODO.md`: VIDEO 미달 시 확인 비활성, VIDEO+QUIZ 영상 잠금, QUIZ 제출 전 점수 판정 불가에 따른 교착 방지, SURVEY/QUIZ 필수 응답 시 제출 비활성 등 현행 정책과 기존 자동 검증 기록.
- `docs/policies/POL-06.md`: SURVEY·QUIZ 선택·제출 정책; VIDEO+QUIZ 영상만 완료해도 QUIZ가 완료된 것은 아님.
