## 3. 데이터 이관 (PostgreSQL → Oracle)

운영 데이터가 PostgreSQL에 있다면 다음 순서로 이관한다. 개발 샘플만 있다면 이관하지 않는다.

1. 조직 마스터 → 템플릿 → 문항 → 선택지 → 팝업 → 콘텐츠 → 대상 → 상태 → 응답 → 영상 → 로그 순 (FK 순서).
2. IDENTITY 값은 그대로 삽입하고, 이관 후 각 시퀀스를 `MAX(id)+1`로 재설정.
3. `content_options` JSONB → 텍스트 그대로 CLOB (IS JSON 통과 확인).
4. `TIMESTAMP` 값은 원본이 KST 로컬 시각이므로 변환 없이 이관. `AT TIME ZONE` 후처리 불필요.
5. 이관 후 `03_validation.sql`(참조 저장소)을 Oracle 문법으로 옮겨 건수·대상 계산 결과를 대조.

## 4. 미결 사항 (정책 확정 필요)

| # | 항목 | 현행/설계 처리 | 확정 필요 내용 |
|---|---|---|---|
| 1 | Oracle 버전 | 19c 가정 | 12.1 이하면 식별자 30자 제한·`IS JSON` 미지원 대응 |
| 2 | 통합 토큰 연동 (타 팀) | WPF `IAuthHeaderProvider` 확장 지점 + 서버 `WpfUserResolver` 어댑터만 준비 | 타 팀과 합의: `/p/api/wpf/**` 필터 적용 방식, Authentication의 사번 필드, WPF가 SSO 토큰을 얻는 방법 (04 문서 §4) |
| 3 | 조직 마스터 소스 | `APP_*` 테이블 유지 | 운영 HR 마스터와의 동기화 또는 뷰 대체 |
| 4 | 반복/예약 노출 | 컬럼 보존, 로직 없음 | `periodMode` 값별 재노출·완료 초기화 규칙 |
| 5 | QUIZ 미통과 재응시 | 미통과 시 재노출(현행 유지) | 재응시 횟수 제한 여부 |
| 6 | 응답 이력 | 사용자+팝업 최신 1건 upsert(현행 유지) | 시도별 이력 보관 필요 여부 |
| 7 | SURVEY 채점 데이터 정규화 | 결과 API는 채점 안 함. 서버 저장 정규화는 미반영 | `saveAdminQuestions` 수정 허용 여부 (기존 서비스 수정) |
| 8 | 템플릿 버전 정책 | 현행 유지(수정마다 새 그룹) | 참조 저장소 P0 항목 |
| 9 | 토큰 유효기간·폐기 정책 | 타 팀 통합 토큰 정책에 따름 | WPF 401 재시도 횟수(현재 1회)만 우리 결정 |
| 10 | 결과 큐 보존 기간 | 무기한(전송 성공 시 제거) | 장기 미전송 항목 폐기 기준 |
| 11 | 구 WPF API 제거 시점 | 단계 8 | 병행 운영 기간 |
| 12 | 영상 파일 서빙(`PopupVideoController`) 인증 | 공개 유지 | WPF 토큰 요구 여부 (WebView2 요청 헤더 주입 필요) |
| 13 | WPF WebView2 SDK 버전 불일치 | csproj `1.0.3124.44` vs `OFFLINE_WPF_BUILD.md`·오프라인 nupkg `1.0.4078.44` (베이스라인부터) | 운영 PC Runtime에 맞춰 하나로 통일. 오프라인 빌드 시 nupkg 버전 확인 |

## 5. 위험과 완화

| 위험 | 완화 |
|---|---|
| 기존 `PopupMapper.xml` Oracle 변환 중 의미 변경 | 구문별 변환표(05 §5) 기준으로 1:1 대조. 관리자 화면 왕복 테스트 |
| 타 팀 통합 토큰 필터가 `/p/api/wpf/**`에 적용되기 전까지 사용자 식별 공백 | 개발 프로파일에서만 `X-Dev-User-Id` 허용. 운영 프로파일은 `dev-user-header=false` 고정, 필터 적용 전 운영 배포 금지 |
| 결과 전송 유실로 완료 상태 누락 | 로컬 큐 + 멱등 키 + 시작 시 flush |
| 팝업 열림 중 주기 조회로 중복 표시 | `HasOpenPopups`면 조회 건너뜀 |
| Oracle `IN` 절 1000개 제한 | 템플릿·문항 ID 수가 소규모. 초과 시 분할 조회 |
